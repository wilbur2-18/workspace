SYSTEM ARCHITECTURE · DISCUSSION DRAFT

综合分析平台系统架构图

以当前前端原型为基础反推系统分层：用户从前端应用进入审计作业，前端调用业务服务，业务服务统一管理四类数据资源，并向下调度智能执行、存储和外部系统能力。

前端应用 业务服务 智能执行 数据资源 基础存储 外部系统
使用入口 API / 业务服务 资源管理 智能执行 存储与外部接入

用户层

USER
审计人员 资料治理、任务执行、对话分析、结果复核、证据追溯
管理员 用户权限、数据源、模型、共享资源与系统配置

用户不直接面对底层模型和数据系统，主要通过工作台和技能库完成审计作业。

前端应用层

CLIENT
工作台页面 资源区 / 审计助手 / 任务结果区
技能库页面 我的技能 / 共享技能 / 版本回退
系统管理页面 数据源、模型、用户、角色等配置入口

业务应用服务层

SERVICE
工作台服务 项目空间、共享、权限范围
资源管理服务 上传、目录、状态、预览、引用
技能服务 配置、共享、版本、工作台级技能
审计助手服务 会话、上下文、敏感操作确认
任务服务 单次、跑批、打包、生成技能任务
结果服务 结果树、编辑、下载、历史版本

数据资源层

DATA
文件资料 PDF、Word、Excel、图片、ZIP
数据库 / 库表 业务库、表结构、字段、行数据
数据图谱 实体、关系、路径、子图
知识库 制度、规范、案例、风险清单

智能执行层

AI RUNTIME
解析与治理管线 OCR、格式转换、表格拆分、要素抽取
检索与证据引擎 全文检索、向量检索、引用定位
Agent 编排器 计划、工具调用、多步骤执行
技能运行时 规则包、抽取配置、审计思路
任务队列与调度 排队、执行、中止、失败、重跑
模型网关 大模型、视觉模型、Embedding

基础存储层

STORAGE
业务元数据 工作台、资源、技能、任务、结果、权限关系
对象存储 原始文件、预览文件、导出包、附件
检索索引 OCR 文本、文档分块、向量索引、字段索引
审计日志 操作记录、工具调用、审批确认记录

外部系统 / 数据源

SOURCE
业务系统 ERP、财务、合同、OA、发票、支付、供应商
图谱平台 审计图谱、资金流向图谱、供应链图谱
知识库平台 制度库、规范库、案例库、风险规则库
模型与工具服务 私有化模型、工具网关、第三方能力

审计作业主链路

1 工作台创建或进入审计项目空间
2 数据资源接入文件、库表、图谱、知识库
3 技能引用、创建或维护审计技能
4 任务 / 对话创建任务或通过助手发起分析
5 AI 执行调度模型、工具、检索和技能运行时
6 结果生成 Markdown 结果、证据链和任务产物
7 沉淀复核后保存结果或总结为新技能

四类数据资源定位

资源 系统定位
文件资料 已较完整非结构化资料入口，经过解析、OCR、抽取后进入检索与证据链。
库表 已体现结构化业务数据入口，作为任务和技能执行的可选资源。
图谱 已体现关系型审计线索入口，支撑穿透、路径和关系解释。
知识库 偏预留制度、规范、案例、风险清单入口，后续支撑依据检索与规则约束。
