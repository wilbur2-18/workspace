# 技能推荐置顶

**产品**：综合分析平台 / 技能库  
**状态**：待开发  
**更新**：2026-07-03  
**关联材料**：技能库公共技能页；`demo.html#template?tab=shared`

---

## 1. 需求背景

公共技能数量增加后，管理员需要把高频、重点或标准化程度较高的技能优先展示，降低用户在技能库中查找常用技能的成本。

本次优化重点是在公共技能列表中增加推荐置顶管理能力，让管理员可以对单个或多个公共技能设置推荐状态，并让推荐技能默认排在列表顶部。

---

## 2. 目标场景

管理员维护公共技能时，可以快速将重点技能设置为推荐；用户进入公共技能列表时，优先看到被推荐的技能。管理员需要集中处理多个技能时，可以进入批量操作模式完成推荐、取消推荐、导出和全部选择。

---

## 3. 本次做什么

### 3.1 推荐置顶

| 对象 | 规则 |
| --- | --- |
| 支持范围 | 仅公共技能支持推荐置顶 |
| 列表排序 | 被推荐技能默认排在普通技能前面；推荐技能内部继续遵循当前排序口径 |
| 推荐标识 | 被推荐技能在卡片上展示`推荐`标识 |
| 单个操作 | 管理员可在单个公共技能的更多操作中执行`推荐置顶`或`取消推荐` |

说明：

1. 推荐置顶不改变技能本身的发布、公开、停用、分类和版本规则。
2. 推荐状态只影响公共技能列表中的展示优先级，不改变技能市场或工作台技能列表。

### 3.2 批量操作

公共技能列表支持进入批量操作模式。批量模式用于集中处理当前列表中的公共技能，不改变卡片原有的基本信息和配置能力。

| 操作 | 规则 |
| --- | --- |
| 进入批量 | 批量操作入口位于公共技能列表筛选排序区，管理员点击后进入批量模式 |
| 退出批量 | 退出批量模式时清空当前选择 |
| 勾选展示 | 默认不展示勾选框；进入批量模式后，卡片左侧图标位置替换为勾选框 |
| 卡片点击 | 批量模式下点击卡片只切换选中状态，不打开技能配置弹窗 |
| 已选数量 | 批量操作区展示当前已选公共技能数量 |

批量操作区支持：

1. `全部选择`
2. `批量推荐置顶`
3. `批量取消推荐`
4. `批量导出`
5. `清空选择`

### 3.3 全部选择与批量导出

1. `全部选择`只选择当前搜索、筛选和类型页签条件下可见的公共技能。
2. 当前可见公共技能已全部选中时，`全部选择`不可点击。
3. 未选择技能时，`批量推荐置顶`、`批量取消推荐`和`批量导出`不可点击。
4. `批量导出`仅导出已选公共技能。
5. 选中多个技能时，导出为一个批量 JSON 文件；选中单个技能时，沿用单技能导出口径。

---

## 4. 本次不做什么

1. 不拆分为推荐列表和普通技能列表。
2. 不支持技能市场、工作台技能或私有技能的推荐置顶。
3. 不做手动拖拽排序、推荐权重或推荐有效期配置。
4. 不做自动推荐算法。
5. 不新增批量导入能力。
6. 不调整公共技能的发布、停用、分类、版本和权限规则。

---

## 5. 验收口径

1. 管理员进入技能库公共技能页后，已推荐技能默认排在普通技能前，并展示`推荐`标识。
2. 管理员通过单个公共技能更多操作设置推荐后，该技能进入推荐状态；取消推荐后不再置顶。
3. 管理员进入批量模式后，公共技能卡片左侧图标位置替换为勾选框。
4. 批量模式下点击卡片，只切换选中状态，不打开技能配置弹窗。
5. 管理员点击`全部选择`后，当前筛选结果中的公共技能全部被选中，已选数量同步更新。
6. 未选择技能时，批量推荐、批量取消推荐和批量导出均不可点击。
7. 选择技能后，批量推荐、批量取消推荐和批量导出可点击，并只对已选公共技能生效。
8. 管理员点击`清空选择`或退出批量模式后，已选状态被清空。
9. 选中多个技能并点击`批量导出`后，系统生成一个包含已选技能的批量 JSON 文件。
