# 对话中图谱模板精准调用

**产品**：综合分析平台  
**状态**：待梳理  
**更新**：2026-05-26  
**关联材料**：工作台图谱资源；对话引用资源；任务资源配置；数据图谱平台模板

---

## 1. 原始需求 / 背景

对话中的图谱资源，应该可以看到可用的模板，确保模板可以精准的调用。

---

## 2. 初步理解

当前对话可以引用图谱资源，但大模型在使用图谱时，需要知道当前图谱有哪些可用模板，以及每个模板适合解决什么问题。

本需求重点不是新增图谱分析能力，而是把“可用模板”作为图谱资源的一部分在对话中暴露出来，让大模型可以按用户意图选择正确模板，减少误调用、错调用或泛化回答。

---

## 3. 目标场景

用户在对话中引用某个图谱资源并提出分析问题时，大模型可以识别该图谱可用的模板，选择匹配的模板发起调用，并在无法确定模板时向用户说明或追问。

---

## 4. 初步范围

| 对象 | 初步规则 |
| --- | --- |
| 图谱资源 | 对话上下文中展示图谱名称、类型、可用模板列表和模板状态 |
| 图谱模板 | 向大模型揭露模板名称、用途、输入要求、输出结果和适用条件 |
| 模板调用 | 大模型调用模板时，应传入模板标识，避免只按模板名称模糊匹配 |
| 不可用模板 | 不进入可调用范围，必要时展示不可用原因 |
| 多模板匹配 | 如果多个模板都可能适用，优先让用户选择或让模型说明选择依据 |

说明：

- 模板需要有稳定 ID，不能只依赖自然语言名称调用。
- 对话中展示给用户的模板信息可以简化，但给大模型的工具上下文需要足够明确。
- 图谱资源被删除、无权限或模板下线时，对话中不应继续调用该模板。

---

## 5. 影响面与风险

1. 影响图谱资源详情、对话资源引用、工具调用参数和模型上下文构造。
2. 需要明确模板元数据口径，否则大模型难以判断模板适用场景。
3. 如果模板名称相似或用途重叠，容易出现误调用，需要有歧义处理。
4. 与任务配置中的图谱资源选择、应用中心模板、SkillHub 能力资产可能存在交叉。

---

## 待确认问题

| 问题 | 影响 |
| --- | --- |
| 图谱模板具体指查询模板、分析模板，还是图谱平台的业务模板 | 影响模板元数据和调用方式 |
| 模板列表是在图谱资源详情中展示，还是只在对话引用后展示 | 影响交互入口 |
| 多个模板都匹配用户问题时，是由模型自动选择还是让用户选择 | 影响对话流转和歧义处理 |
