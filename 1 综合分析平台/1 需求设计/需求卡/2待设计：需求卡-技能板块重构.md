# 技能板块重构

**产品**：综合分析平台  
**状态**：待设计  
**更新**：2026-06-09  
**关联材料**：工作台技能区；组织技能库；历史分类口径；历史版本口径；SkillHub 统一技能管理平台；对话快捷引用与技能调用

---

## 1. 需求背景

当前技能流转存在三层关系：用户先在“我的技能”中创建、导入或沉淀技能，再将技能引用到具体工作台；其他人可用的技能则通过“共享技能”流转。这个机制把“个人技能层”放在组织技能和工作台使用之间，导致用户在工作台内使用技能时还要先理解“我的技能 / 共享技能 / 工作台技能”的关系。

实际使用中，“我的技能”既不是组织公共资产，也不是工作台实际执行对象，层级价值不清。它带来几个问题：工作台使用路径变长；协作工作台中创建的技能归属不清；用户离开工作台后可能出现无人维护的技能；技能复用、编辑权限和版本责任也难以追溯。

本次重构重点是收缩技能层级：技能库展示权限范围内可用的技能，工作台管理当前工作台实际使用和维护的技能。技能既可以从组织库添加到工作台，也可以在工作台创建后共享给指定组织或用户。

---

## 2. 目标场景

审计人员在工作台开展分析时，可以直接添加组织技能并在当前工作台使用；也可以把当前工作台中沉淀出的技能共享给指定组织或用户。共享完成后，共享范围内的用户即可看到并添加使用。

---

## 3. 本次做什么

### 3.1 技能层级调整

技能板块调整为两层：

| 层级 | 定位 | 主要动作 |
| --- | --- | --- |
| 组织技能库 | 权限范围内可见的可复用技能列表 | 浏览、搜索、查看详情、添加到工作台 |
| 工作台技能区 | 当前工作台实际使用和维护的技能 | 添加、创建、编辑、分类、版本、执行、共享 |

规则：

1. 不再把“我的技能 / 共享技能”作为核心入口或核心资产层级。
2. 技能库只展示当前用户数据权限范围内可见的技能，不展示个人技能列表。
3. 工作台技能区只展示当前工作台已添加或创建的技能。
4. 用户在工作台内创建、导入或生成的技能，直接成为当前工作台技能。

### 3.2 组织技能库

组织技能库本质上按数据权限展示可用技能。

用户可进行：

- 查看权限范围内可见的组织技能。
- 按分类、标签、名称搜索技能。
- 查看技能详情、适用场景、版本信息和共享信息。
- 将技能添加到有权限的工作台。

规则：

1. 工作台技能共享后，立即在共享范围内可见可用。
2. 用户只能看到自己数据权限范围内的技能。
3. 技能的可见范围由共享时选择的组织或用户决定。
4. 共享人、来源工作台、共享时间、共享版本需要记录。

### 3.3 工作台添加技能

工作台技能区提供“添加技能”入口，打开后展示可添加的组织技能。

规则：

1. 用户从工作台添加组织技能后，系统在当前工作台生成可使用、可维护的工作台技能，并保留来源关系。
2. 用户也可以在组织技能库中选择技能，并添加到指定的有权限工作台。
3. 已添加到当前工作台的同源同版本技能展示“已添加”。
4. 同一工作台内技能名称重名时，自动追加序号。
5. 来源技能后续修改、删除或权限变化，不影响当前工作台已添加的技能。

### 3.4 工作台技能权限

工作台技能按工作台权限管理，不按创建人个人归属管理。

| 角色 | 能力 |
| --- | --- |
| 工作台所有者 / 管理员 | 管理本工作台技能，共享给指定组织或用户 |
| 有技能管理权限的协作者 | 编辑、调优、创建版本、共享给指定组织或用户 |
| 普通协作者 | 使用技能，不编辑技能 |
| 已移出工作台的用户 | 不再访问该工作台技能 |

规则：

1. 用户在工作台内创建的技能归属当前工作台，不因创建人退出或权限收回而失效。
2. 创建人、维护人、共享人都是技能操作记录，不作为技能归属层级。
3. 非创建人编辑技能时，版本记录必须体现维护人。

### 3.5 技能共享

工作台技能可以共享给指定组织或用户。

流程：

1. 有技能管理权限的用户选择“共享”。
2. 用户选择共享范围。
3. 系统生成共享记录，并在共享范围内立即可见可用。

共享记录需保留来源工作台、创建人、共享人、共享时间和共享版本。

### 3.6 分类与检索

分类用于组织技能库和工作台技能列表的筛选。

| 对象 | 分类规则 |
| --- | --- |
| 共享技能 | 共享时确认分类；未设置时进入“未分类” |
| 工作台技能 | 支持设置分类；未设置时进入“未分类” |
| 标签 | 可多选，用于辅助检索，不替代分类 |

规则：

1. 一个技能只有一个分类，可有多个标签。
2. 技能列表支持分类、标签、名称搜索叠加筛选。
3. 添加共享技能到工作台时，默认保留来源分类。
4. 批量整理技能时支持移动分类，不改变标签。

### 3.7 版本与留痕

工作台技能和共享技能都需要版本记录。

| 场景 | 规则 |
| --- | --- |
| 保存版本 | 保存技能配置、版本号、版本说明、维护人、维护时间 |
| 查看版本 | 可查看历史版本详情 |
| 回退版本 | 回退前二次确认，可选择是否先保存当前配置为新版本 |
| 执行留痕 | 对话、任务执行时记录使用的技能版本或配置快照 |

说明：

- 共享工作台技能时生成共享版本记录。
- 添加共享技能到工作台后生成工作台技能版本。
- 对话和任务执行记录应能追溯当时使用的技能版本。

---

## 4. 本次不做什么

1. 不保留“我的技能 / 共享技能”作为核心资产层级。
2. 不做组织技能和工作台技能的自动同步。
3. 不允许普通协作者默认编辑工作台技能。
4. 不做版本差异对比。
5. 不把工具、工作流、应用模板纳入本次技能板块重构。

---

## 5. 验收口径

1. 用户进入技能库时，只看到权限范围内可见的技能，不再看到“我的技能 / 共享技能”核心页签。
2. 用户可以在组织技能库中按分类、标签、名称搜索技能，并查看技能详情。
3. 用户可以从组织技能库把技能添加到有权限的工作台。
4. 用户可以在工作台技能区直接打开“添加技能”，选择组织技能并添加到当前工作台。
5. 添加组织技能后，当前工作台生成可使用、可维护的工作台技能，并保留来源关系。
6. 用户在工作台内创建、导入或生成技能后，该技能直接进入当前工作台技能区。
7. 创建人退出工作台后，工作台管理员仍可管理该技能。
8. 工作台技能支持分类、标签和名称搜索，未分类技能进入“未分类”。
9. 有技能管理权限的用户编辑技能后，系统记录维护人、维护时间、版本说明和配置快照。
10. 有技能管理权限的用户可以将工作台技能共享给指定组织或用户；共享完成后，共享范围内用户可立即看到并添加使用。
