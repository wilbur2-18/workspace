# 综合分析平台 · 需求卡

本目录集中管理综合分析平台需求卡。

## 当前内容

| 内容 | 说明 |
| --- | --- |
| `遗留问题清单.md` | 已上线需求中的未完成细节和后续跟进项。 |
| `1待梳理：需求卡-*.md` | 需求背景、目标和范围还在收敛，允许保留待确认问题。 |
| `2待设计：需求卡-*.md` | 需求口径已基本明确，下一步进入交互和 UI 设计。 |
| `3待开发：需求卡-*.md` | 需求和设计均已明确，可以给到开发实现。 |
| `x 已上线/` | 已上线需求卡归档，仅作为历史记录保留。 |

## 维护规则

- 新增需求卡时，放在本目录下。
- 状态变化时，优先更新文件名前缀，并同步更新卡片正文状态。
- 不按状态继续拆 `待梳理 / 待设计 / 待开发` 目录，避免频繁移动文件；状态由文件名前缀和卡片正文共同表达。
- 已上线需求卡放入 `x 已上线/`，不再参与当前排期。
- 已上线需求仍有未完成细节时，需求卡保持已上线状态，未完成细节记录到 `遗留问题清单.md`。
- 临时分析、架构梳理和一次性讨论材料不放在这里，应进入 `../../x 杂七杂八/<事项>/`。
