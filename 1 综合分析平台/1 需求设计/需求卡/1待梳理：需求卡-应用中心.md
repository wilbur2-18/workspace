# 应用中心

**产品**：综合分析平台 / 应用中心  
**状态**：待梳理  
**更新**：2026-05-25  
**关联材料**：任务监管板块、创建任务弹窗、批量打包下载任务、SkillHub、现有工作台三栏布局

---

## 1. 原始需求 / 背景

需要新增“应用中心”：和任务衔接，也支持自定义开发注入，服务于审计人员进行快捷的 AI 应用，比如上传文件，然后等待执行，最后拿到结果。需要深度收集信息后再设计。

这个模块本质上不是普通功能菜单，而是把可复用的 AI 审计能力包装成审计人员能直接启动的应用。

---

## 2. 信息收集摘要

### 2.1 本地产品现状

- 综合分析平台当前核心闭环是“资料输入 - 技能执行 - 助手协同 - 结果沉淀”。
- 工作台内已有任务创建、任务列表、任务详情、结果沉淀、打包下载任务等能力。
- 当前三栏工作台适合做具体审计作业，不适合承载大量可浏览、可启动、可维护的应用目录。

### 2.2 外部参考

| 参考对象 | 可借鉴点 |
| --- | --- |
| Dify 应用 / 模板市场 | 用户发现应用模板，一键采用，按步骤配置模型、工具、数据源并运行测试 |

## 3. 初步理解

应用中心要解决的是“审计人员不想配置完整技能和任务，只想启动一个明确的 AI 审计小应用”。

典型路径：

1. 用户进入应用中心。
2. 选择一个应用，如“合同关键条款提取”“整改报告合规检查”“财政数据异常初筛”。
3. 上传或选择资料，填写少量参数。
4. 系统创建后台任务。
5. 用户在任务列表查看进度。
6. 任务完成后下载、查看或沉淀结果。

应用中心和 SkillHub 的关系：

- SkillHub 管“能力资产”：技能、工具、工作流、版本、权限。
- 应用中心管“用户入口”：把能力包装成可启动、可等待、可拿结果的业务应用。

---

## 4. 参考方案

### 方案 A：应用启动器

把应用中心做成审计 AI 应用目录，重点服务业务人员快速启动。

- 应用卡片展示名称、用途、适用资料、预计耗时、输出结果。
- 点击应用后进入启动弹窗 / 启动页。
- 用户上传文件或选择工作台资源，填写必要参数。
- 提交后创建任务，后续在任务列表查看和取结果。

适合首版，用户价值最直接。

### 方案 B：任务模板中心

把应用中心理解为“可复用任务模板”。

- 每个应用对应一类任务模板。
- 应用启动后，本质是创建一个预配置任务。
- 任务名称、输入资源、输出位置、执行技能、参数由应用模板预置。
- 更容易和现有任务系统打通。

实现路径清晰，但应用感会弱一些。

### 方案 C：AI 应用开放平台

支持内部开发者或厂商把自定义应用注入平台。

- 支持自定义应用注册：应用信息、入口表单、参数 Schema、执行接口、输出格式。
- 支持接入 SkillHub 能力、MCP / API 工具、工作流服务。
- 支持应用审核、权限、版本、上架、下架。
- 支持运行日志、失败原因、调用统计。

扩展性强，但首版复杂度高，建议作为二期能力。

---

## 5. 初步范围

首版建议聚焦“应用启动器 + 任务衔接”：

1. 应用中心作为独立入口，展示可用 AI 审计应用。
2. 应用支持分类、搜索、标签、适用场景、收藏 / 最近使用。
3. 应用详情展示：用途、输入要求、输出结果、预计耗时、使用说明、维护来源。
4. 启动应用时打开配置弹窗 / 启动页，支持上传文件、选择资源、填写参数。
5. 点击运行后创建任务，任务进入统一任务列表。
6. 任务完成后从任务详情查看结果、下载产物或沉淀到结果树。
7. 应用来源支持平台预置、SkillHub 发布、自定义开发注入。

---

## 6. 影响面与风险

- 应用中心会放大任务系统的重要性，需要统一任务状态、进度、失败、重跑、产物下载。
- 应用与技能、工作流、工具的关系需要清楚，否则容易和 SkillHub 重叠。
- 自定义开发注入涉及安全审核、参数 Schema、接口权限、运行沙箱和日志追踪，首版不宜做深。
- 应用启动时的输入方式要与现有资源树、结果树、数据库表选择保持一致。
- 对审计机关来说，应用必须可控、可审计、可追溯，不能只是“谁都能发布的小工具市场”。

---

## 待确认问题

| 问题 | 影响 |
| --- | --- |
| 应用中心首版是平台级入口，还是工作台内入口 | 决定导航和数据范围 |
| 应用运行结果默认进入任务详情、结果树，还是两者都进入 | 决定结果沉淀链路 |
| 上传文件型应用是否自动创建临时工作台 / 临时资源区 | 影响“上传即用”的体验 |
| 自定义开发注入首版是否只做登记和展示，不开放在线开发 | 控制实施复杂度 |
| 应用是否必须绑定 SkillHub 中的技能 / 工作流版本 | 影响可追溯和复现 |
| 应用权限按组织、项目、角色还是应用自身授权 | 影响审计厅 / 审计署分级管理 |
