# 信息统计优化

**产品**：综合分析平台  
**状态**：待开发  
**更新**：2026-07-03  
**关联材料**：系统管理 / 信息统计；已上线需求卡《用户用量统计》；原型 `综合分析平台 20260701/demo.html#settings`

---

## 1. 需求背景

AI 审计试点单位管理者需要判断平台是否真正覆盖到下级地区、部门和用户，并能快速看到谁用得多、谁活跃、谁在建设技能。原有用量统计更偏 Token 和用户榜单，难以支撑“试点成效”汇报。

本次优化在保留已有用量统计基础上，补齐覆盖、活跃、技能建设和趋势查看能力，让管理者少操作也能看到重点结果。

---

## 2. 目标场景

管理员进入系统管理的信息统计页后，可以按组织范围和时间范围查看平台使用情况；默认即可看到 8 个核心指标、3 类重点榜单、组织统计和用户统计，并能点开单个指标查看趋势明细和导出。

---

## 3. 本次做什么

### 3.1 统计范围

页面顶部提供统一统计组织范围、时间范围和刷新入口。

| 控件 | 规则 |
| --- | --- |
| 组织范围 | 默认全部组织；支持从组织树选择一个组织；影响指标卡、重点榜单、组织统计和用户统计 |
| 时间范围 | 支持最近 1 小时、最近 1 天、最近一周、最近 1 月、最近半年、最近 1 年快捷范围，也支持自定义起止时间 |
| 刷新 | 按当前组织范围和时间范围刷新页面统计 |

说明：

- 默认时间范围为最近一周。
- 点击组织统计表行只切换下方用户统计范围，不改变顶部组织范围，也不影响重点榜单。

### 3.2 指标卡

顶部固定展示 8 个指标卡，每张卡展示当前值、较上期变化和小趋势图。

| 指标 | 口径 |
| --- | --- |
| Token 总量 | 当前范围内的大模型 Token 消耗总量 |
| 调用次数 | 当前范围内的大模型调用次数 |
| 地区覆盖率 | 有使用记录的地区数 / 地区总数 |
| 部门覆盖率 | 有使用记录的部门数 / 部门总数 |
| 开通账号数 | 当前可统计范围内已开通的平台账号数量 |
| 使用人数 | 当前时间范围内产生过使用行为的用户数量 |
| 最高日活 | 当前时间范围内单日活跃用户峰值 |
| 平均日活 | 当前时间范围内日活跃用户平均值 |

点击任一指标卡，打开该指标的趋势分析弹窗。

### 3.3 重点榜单

8 个指标下方展示“重点榜单”，默认展示“部门榜单 / 地市局级”。榜单只做展示和导出，不联动下方组织统计或用户统计。

| 维度 | 层级 |
| --- | --- |
| 地区榜单 | 省级、地市级、区县级 |
| 部门榜单 | 省厅级、地市局级、区县局级 |
| 用户榜单 | 不展示层级选择 |

每个维度下展示 3 个 Top 5 榜单：

| 榜单 | 排序规则 | 展示内容 |
| --- | --- | --- |
| 资源使用榜 | Token 用量降序；调用次数作为同值兜底 | 对象、Token 用量、调用 |
| 应用活跃榜 | 对话数 + 任务数降序；对话数、任务数作为同值兜底 | 对象、交互总数、对话 / 任务 |
| 技能建设榜 | 技能创建数降序；Token 用量作为同值兜底 | 对象、技能创建 |

每个榜单提供导出入口，导出当前维度、层级、组织范围和时间范围下的全量数据，不只导出 Top 5。

### 3.4 指标趋势弹窗

指标趋势弹窗用于查看单个指标的趋势，不做多指标对比。

规则：

- 弹窗打开时默认带入页面顶部已选组织范围和时间范围。
- 弹窗内可单独调整组织范围和时间范围，不反向改变页面顶部筛选。
- 默认自动选择统计颗粒度：最近 1 小时按 10 分钟，最近 1 天按小时，最近一周和最近 1 月按日，最近半年和最近 1 年按月。
- 若当前时间范围只有一个可用颗粒度，不展示颗粒度控件。
- 趋势图下方展示趋势明细表，统计周期需包含年份，例如 `2026-01`、`2026-01-01（星期一）`。
- 趋势明细支持导出。

### 3.5 组织统计与用户统计

组织统计保留树形表格，并展示范围和默认排序标签。

| 表格 | 规则 |
| --- | --- |
| 组织统计 | 默认按 Token 用量降序；父级组织可展开，下属需包含“本级”节点；行统计本组织及下级组织 |
| 用户统计 | 默认按 Token 用量降序；点击组织统计行后，仅切换用户统计范围；可取消选中恢复顶部组织范围 |

组织统计字段：统计对象、开通账号、当前时间范围使用、使用率、平均日活、最高日活、Token 用量、调用次数。

用户统计字段：排名、用户、所属组织、Token 用量、调用、对话、任务、工作台创建、技能创建。

说明：

- 用户列只展示姓名，不展示账号。
- 排名列只展示当前列表顺序，不提供排序控制。
- 组织统计和用户统计分别提供导出入口，导出不受表格分页或展开状态影响。

### 3.6 页面体验要求

- 页面内部滚动时，信息统计页头需固定在内容容器顶部；页头背景应完整遮挡下方内容，不显示额外下划线。
- 指标卡右侧小趋势图使用图表组件承载，随卡片宽度自适应，避免手绘静态曲线。
- 重点榜单、组织统计和用户统计中的范围、层级、默认排序信息用轻量标签展示，避免重复说明文字撑高行高。
- 指标趋势弹窗遵循统一弹窗结构：标题在弹窗头部，关闭按钮在右上角；正文只保留筛选控件、趋势图、趋势明细和导出入口。

---

## 4. 本次不做什么

1. 不做费用结算、额度扣减或账单管理。
2. 不拆分输入 Token 和输出 Token。
3. 不做多指标综合评分、权重公式或综合排名。
4. 不把重点榜单点击作为筛选入口。
5. 不把工作台创建数纳入应用活跃榜排序。
6. 不做按周趋势颗粒度。
7. 不做整页统一导出。

---

## 5. 验收口径

1. 管理员进入信息统计页后，默认看到全部组织、最近一周的 8 个指标卡。
2. 时间范围选择器支持最近 1 小时、最近 1 天、最近一周、最近 1 月、最近半年、最近 1 年快捷范围。
3. 指标卡展示 Token 总量、调用次数、地区覆盖率、部门覆盖率、开通账号数、使用人数、最高日活、平均日活。
4. 切换顶部组织范围或时间范围后，指标卡、重点榜单、组织统计和用户统计按当前范围刷新。
5. 重点榜单默认展示部门榜单 / 地市局级，并展示资源使用榜、应用活跃榜、技能建设榜各 Top 5。
6. 切换地区榜单、部门榜单、用户榜单时，层级控件按规则显示或隐藏。
7. 每个重点榜单点击导出后，导出当前范围下的全量数据。
8. 点击任一指标卡后，趋势弹窗默认带入页面当前组织范围和时间范围，只展示该单个指标趋势。
9. 趋势明细表的统计周期包含年份，并支持导出。
10. 点击组织统计行后，仅用户统计范围变化；重点榜单和顶部组织范围不变化。
11. 组织统计、用户统计默认按 Token 用量降序；用户统计排名列不提供排序控制。
12. 组织统计和用户统计的导出入口可分别导出当前范围数据。
13. 页面内部滚动时，信息统计页头固定且背景遮挡完整。
14. 指标趋势弹窗只保留单指标趋势图和趋势明细表，无冗余范围摘要或口径说明。
