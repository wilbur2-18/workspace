# 技能库分类

**产品**：综合分析平台  
**状态**：待梳理  
**更新**：2026-05-22  
**关联材料**：技能库；技能创建 / 编辑弹窗；技能库标签筛选与排序

---

## 1. 需求背景

当前技能库已有“我的技能 / 共享技能”、搜索、标签筛选和排序能力。随着技能数量增加，仅依赖名称搜索和标签会让用户先定位大类技能的成本变高。

本次需求新增“分类”作为技能的主归属，用于稳定组织技能资产；标签继续作为灵活检索补充，不替代分类。

---

## 2. 目标场景

用户进入技能库后，可以先按业务分类缩小技能范围，再结合搜索、标签和排序找到目标技能；用户创建、导入、复制或整理技能时，也能为技能指定一个稳定分类。

---

## 3. 本次做什么

### 3.1 分类口径

| 对象 | 规则 |
| --- | --- |
| 分类 | 技能的主归属，一个技能只有一个分类 |
| 标签 | 技能的多维特征，一个技能可有多个标签 |
| 未分类 | 未设置分类的技能统一进入“未分类” |
| 我的 / 共享 | “我的技能”和“共享技能”分别统计和筛选分类 |

### 3.2 分类入口与筛选

- 在技能库现有控制区增加“分类”筛选入口，位置靠近“标签”和“排序”。
- 分类选项包含“全部”“未分类”和预置业务分类。
- 选择分类后，技能列表只展示当前页签下属于该分类的技能。
- 分类与搜索、标签、排序叠加生效：先按分类限定范围，再搜索 / 标签筛选，最后排序。
- 分类数量统计当前页签下对应分类的技能数量。

### 3.3 技能创建、编辑与流转

| 场景 | 分类规则 |
| --- | --- |
| 创建技能 | 增加“分类”字段；在某分类下创建时默认带入当前分类 |
| 编辑技能 | 可修改分类；修改分类不影响标签 |
| 导入技能 | 有分类字段则带入；无分类字段进入“未分类” |
| 复制共享技能到我的技能 | 默认保留原分类，复制后可在“我的技能”中调整 |
| 共享我的技能 | 共享时带出当前分类；未分类技能共享后仍为“未分类” |

### 3.4 列表展示与批量整理

- 技能卡片展示分类信息，视觉上与标签区分。
- 已有批量选择能力中增加“移动分类”，用于把选中的可编辑技能移动到同一分类。
- 批量移动分类只修改分类，不新增、删除或覆盖标签。

---

## 4. 本次不做什么

1. 不做分类后台管理、分类新增 / 改名 / 排序。
2. 不做二级分类。
3. 不做智能推荐分类。
4. 不做分类权限体系。
5. 不改变技能执行、共享和历史版本回退逻辑。

---

## 5. 验收口径

1. 用户进入技能库后，可以在“我的技能”和“共享技能”下按分类筛选技能。
2. 分类、搜索、标签、排序可叠加生效，筛选结果与当前条件一致。
3. 未设置分类的技能统一展示在“未分类”中。
4. 用户创建、编辑、导入、复制、共享技能时，分类按本卡规则保留或进入“未分类”。
5. 用户批量移动分类后，选中技能的分类变化，原有标签保持不变。
6. 分类为空或筛选无结果时，空态文案能说明是分类为空还是条件筛选无结果。
