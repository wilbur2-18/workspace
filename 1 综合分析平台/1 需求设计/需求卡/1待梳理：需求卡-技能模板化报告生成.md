# 技能模板化报告生成

**产品**：综合分析平台  
**状态**：待梳理  
**更新**：2026-06-18  
**关联材料**：技能配置；技能执行；任务结果；工作底稿；审计报告；文档结果预览与下载

---

## 1. 原始需求 / 背景

记录需求：

1. 希望技能支持上传模板，可以基于模板进行报告生成。
2. 希望可以生成标准格式的工作底稿、审计报告，包括字体、排版、表格等格式要求。

---

## 2. 初步理解

这个需求不是单纯让大模型生成一段报告内容，而是让“技能”具备模板化文档生成能力。用户希望在技能中配置或上传标准模板，执行技能后生成符合审计交付要求的工作底稿、审计报告等正式文档。

重点在于输出结果要保留标准格式，包括标题层级、字体字号、段落排版、表格结构、页眉页脚等，而不是只输出 Markdown 或普通文本。

---

## 3. 目标场景

审计人员配置一个“生成审计报告”或“生成工作底稿”的技能时，可以上传单位标准模板。后续在工作台或任务中执行该技能，系统根据资料和技能要求生成一份可预览、可下载、格式符合要求的正式文档。

---

## 4. 初步范围

1. 技能配置中支持上传或关联文档模板。
2. 模板与技能版本建立关系，便于追溯执行时使用的模板。
3. 技能执行时，系统基于模板生成工作底稿、审计报告等文档结果。
4. 结果文件需要保留模板中的字体、排版、表格等格式要求。
5. 结果区支持查看生成结果，并按文档格式下载。

---

## 5. 影响面与风险

1. 影响技能配置、技能版本、任务执行、结果预览和结果下载。
2. 模板生成需要区分“内容生成”和“格式渲染”，不能只依赖大模型自然语言输出。
3. 不同审计单位可能存在不同模板规范，需要明确模板适用范围。
4. 表格、页眉页脚、目录、签章栏等复杂格式可能影响生成稳定性。

---

## 待确认问题

| 问题 | 影响 |
| --- | --- |
| 模板首版支持 DOCX、WPS，还是也支持 Excel / PDF | 影响模板解析和生成链路 |
| 模板是绑定到单个技能，还是可作为组织级模板复用 | 影响模板管理入口 |
| 模板内容通过占位符填充，还是由大模型按模板结构生成 | 影响模板设计规则 |
| 生成结果首版输出 DOCX / WPS / PDF 中哪些格式 | 影响结果预览和下载 |
| 字体、排版、表格等格式是否需要自动校验 | 影响验收口径 |
