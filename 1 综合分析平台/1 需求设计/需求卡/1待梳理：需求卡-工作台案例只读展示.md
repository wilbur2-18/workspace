# 工作台案例只读展示

**产品**：综合分析平台  
**状态**：待梳理  
**更新**：2026-05-26  
**关联材料**：审计助手工作台；案例展示；资源区、对话区、任务区、结果区

---

## 1. 原始需求 / 背景

工作台以及页面支持展示案例，案例中工作台内容不可变更，只读。

---

## 2. 初步理解

平台需要支持“案例展示”场景，让用户查看一套预置或沉淀的审计工作台内容，包括资源、对话、任务、结果等信息。

案例模式下，用户可以浏览、查看和学习案例过程，但不能修改案例中的工作台内容，避免误删、误改或影响标准案例。

---

## 3. 目标场景

用户进入案例页面或打开某个案例工作台后，可以查看案例中的资料、技能使用、任务过程和结果产出，用于演示、培训、复盘或方法参考。

---

## 4. 初步范围

| 区域 | 只读展示规则 |
| --- | --- |
| 资源 | 可查看资源目录、文件信息和预览；不可上传、删除、移动、重命名 |
| 技能 | 可查看案例使用的技能；不可新增、编辑、移除案例技能 |
| 对话 | 可查看历史对话和引用内容；不可继续发送消息 |
| 任务 | 可查看任务配置、执行状态和结果；不可新建、重跑、中止、删除 |
| 结果 | 可查看结果内容和目录结构；不可新增、编辑、删除、移动 |

说明：

- 案例工作台需要有明确的只读状态标识。
- 原有可编辑入口在案例模式下应隐藏、置灰或提示只读，具体交互待设计阶段确定。
- 是否支持“复制案例到我的工作台”可作为后续扩展，不纳入第一版默认范围。

---

## 5. 影响面与风险

1. 影响工作台各区域的按钮、右键菜单、拖拽、快捷操作和批量操作。
2. 需要区分普通工作台和案例工作台的权限模型。
3. 案例内容可能用于演示和培训，需要避免用户操作改变标准案例。
4. 若后续支持复制案例，需要明确复制后的资源、任务和结果归属。

---

## 待确认问题

| 问题 | 影响 |
| --- | --- |
| 案例入口放在工作台内、应用中心，还是单独案例库 | 影响导航和信息架构 |
| 案例是否支持复制为可编辑工作台 | 影响只读模式和后续转化路径 |
| 案例中的任务是否展示真实执行记录，还是只展示结果摘要 | 影响案例数据组织方式 |
