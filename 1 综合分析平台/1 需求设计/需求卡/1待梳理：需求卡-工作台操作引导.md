# 工作台操作引导

**产品**：综合分析平台 / 审计工作台
**状态**：待梳理
**更新**：2026-06-25
**关联材料**：审计工作台；对话输入框附件上传；工作台帮助入口；基础操作引导

---

## 1. 需求背景

新用户进入审计工作台后，容易不知道第一步应该上传材料、输入要求还是查看右侧资源区。本需求先不处理模式选择后的前置提示弹窗，直接从工作台内的第一次操作引导开始，帮助用户完成一条最基础的前端操作路径：上传材料、输入要求、发送对话、看到完成提示。

本卡只记录工作台内的前端交互引导，不覆盖应用中心、简单模式应用流程，也不替代对话区空态引导。

---

## 2. 目标场景

用户首次需要学习工作台基础操作时，可以跟随遮罩引导完成一次“上传材料 - 输入要求 - 发送对话”的真实操作；后续如果还需要学习，可以从工作台帮助入口重新进入“对话改材料”或“复用审计思路”引导。

---

## 3. 本次做什么

### 3.1 触发与起点

1. 本次需求的起点是工作台内的第一次操作引导，不展示、不描述模式选择后的前置提示弹窗。
2. 触发引导后，前端应切回对话主视图，并关闭已展开的帮助弹层、帮助提示或其他会遮挡引导目标的浮层。
3. 引导跟随用户真实操作推进，不通过“下一步”按钮模拟上传、模拟发送或模拟生成结果。
4. 用户关闭、跳过或完成引导后，保留当前工作台状态，不清空已输入内容、已上传附件或已有消息。

### 3.2 基础对话引导步骤

基础对话引导共 3 步，前端需要明确目标元素、遮罩聚焦和气泡位置。

| 步骤 | 引导文案 | 聚焦对象 | 遮罩与气泡 | 推进规则 |
| --- | --- | --- | --- | --- |
| 1. 上传材料 | `上传要修改的材料` | 对话输入框左侧的附件上传按钮 | 开启遮罩，仅高亮附件上传按钮及其可点击热区；气泡位于目标上方 | 用户完成附件选择，且附件进入可发送状态后进入下一步 |
| 2. 输入并发送 | `先输入修改要求，然后点击“发送”` | 对话输入区整体，包含文本输入框和发送按钮 | 开启遮罩，高亮整个输入与发送区域；进入本步时自动聚焦文本输入框；气泡位于输入区上方 | 用户点击发送并成功发起对话后进入下一步 |
| 3. 完成对话 | 标题：`恭喜你，完成一次对话！`<br>说明：`后续可在右侧资源区查看上传的文件和产出的结果。` | 助手回复区域或对话完成后的结果展示区域 | 开启遮罩，高亮回复 / 结果区域；气泡位于目标左侧 | 用户点击 `结束引导` 后关闭引导 |

补充规则：

1. 如果进入第 1 步时用户已经有可发送附件，前端可以直接推进到第 2 步，避免重复要求上传。
2. 如果当前步骤的目标元素暂时不可见，应先切回对应视图并滚动到目标附近；仍无法定位时，兜底聚焦工作台主体区域，避免气泡悬空。
3. 遮罩只用于降低非目标区域干扰，不改变页面布局，不阻断当前步骤目标元素的正常点击。

### 3.3 进度、按钮与退出

| 位置 | 展示规则 |
| --- | --- |
| 进度 | 气泡底部展示点状进度，并展示数字进度 `当前步 / 总步`，基础对话引导为 `1 / 3`、`2 / 3`、`3 / 3` |
| 非最后一步按钮 | 展示 `跳过引导`，点击后关闭当前引导，回到工作台 |
| 最后一步按钮 | 展示主按钮 `结束引导`，点击后关闭当前引导 |
| 关闭按钮 | 用户点击气泡关闭按钮时，按跳过处理，关闭引导并保留当前工作台状态 |

### 3.4 帮助入口复用

工作台保留帮助入口，支持用户后续重新学习。

| 元素 | 文案 / 行为 |
| --- | --- |
| 浮动帮助入口 | 展示 `帮助` |
| 引导结束后的轻提示 | 可提示 `之后可在这里学习`，指向帮助入口 |
| 帮助弹层标题 | `基础操作引导` |
| 引导项 1 | 标题：`对话“改材料”`；说明：`上传材料，输入要求，发送对话。`；点击后重新进入基础对话 3 步引导 |
| 引导项 2 | 标题：`复用审计思路`；说明：`选择审计方法，进行专业审计。`；点击后进入技能使用引导，本卡不展开技能引导细节 |

---

## 4. 本次不做什么

1. 不处理模式选择后的前置提示弹窗交互。
2. 不把简单模式、应用中心和应用使用流程写入本卡。
3. 不重构对话区空态引导。
4. 不新增完整新手任务体系或多模块教学课程。
5. 不定义账号级、服务端级引导完成状态记忆。
6. 不改变上传、发送、技能调用、资源区结果生成等业务逻辑。

---

## 5. 验收口径

1. 触发基础操作引导后，用户直接看到第 1 步 `上传要修改的材料`，不出现模式选择后的前置提示弹窗。
2. 第 1 步遮罩聚焦附件上传按钮，非目标区域变暗，附件上传按钮保持可点击。
3. 用户完成附件上传且附件可发送后，引导自动进入第 2 步。
4. 第 2 步文案为 `先输入修改要求，然后点击“发送”`，遮罩聚焦对话输入区整体，并自动聚焦文本输入框。
5. 用户发送对话后，引导自动进入第 3 步。
6. 第 3 步标题为 `恭喜你，完成一次对话！`，说明为 `后续可在右侧资源区查看上传的文件和产出的结果。`。
7. 引导气泡始终展示点状进度和数字进度，基础对话引导总步数为 3。
8. 非最后一步按钮文案为 `跳过引导`，最后一步主按钮文案为 `结束引导`。
9. 用户跳过、关闭或结束引导后，当前输入内容、已上传附件和已有消息不被清空。
10. 帮助入口中可以看到 `基础操作引导`，并至少提供 `对话“改材料”` 和 `复用审计思路` 两个引导项。
