# 表格结果生成与预览

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-06-01  
**关联材料**：对话工具调用；结果树；结果文件预览

---

## 1. 需求背景

当前结果文件主要按 Markdown 展示。随着大模型开始生成结构化表格结果，需要支持创建和编辑 Excel 类结果，并在结果文件中预览表格内容。

---

## 2. 目标场景

用户在对话中让大模型生成或调整表格结果后，可以在结果树中看到对应结果文件，并打开预览 CSV、TSV、XLSX 内容。

---

## 3. 本次做什么

### 3.1 工具调用

- 大模型支持调用“创建 Excel”工具，生成新的表格结果文件。
- 大模型支持调用“编辑 Excel”工具，更新已有表格结果文件。
- 表格结果文件进入结果树，作为结果文件展示。

### 3.2 表格预览

- 结果文件支持预览 CSV、TSV、XLSX 内容。
- 表格预览为只读，暂不支持用户手动编辑单元格。
- 表格结果与 Markdown 结果使用不同预览方式，不强行转成 Markdown 展示。

### 3.3 表格结果操作限制

表格结果暂不支持以下操作：

- 复制内容。
- 下载为 PDF。
- 下载为 Word。

表格结果下载时保持原表格格式：CSV 下载为 CSV，TSV 下载为 TSV，XLSX 下载为 XLSX，不转成 Markdown。

---

## 4. 本次不做什么

1. 不做表格手动编辑。
2. 不做公式、样式、合并单元格等复杂 Excel 能力。
3. 不做表格结果转 PDF 或转 Word。
4. 不做表格结果转 Markdown 下载。
5. 不改变 Markdown 结果的复制和下载能力。

---

## 5. 验收口径

1. 大模型调用“创建 Excel”工具后，结果树中生成表格结果文件。
2. 大模型调用“编辑 Excel”工具后，已有表格结果内容被更新。
3. 用户打开 CSV、TSV、XLSX 结果文件时，可以看到表格预览。
4. 表格预览中不展示手动编辑入口。
5. 表格结果不展示复制、下载为 PDF、下载为 Word 操作。
6. 表格结果下载后仍为原表格格式，不转为 Markdown。
7. Markdown 结果仍保留原有复制和下载操作。
