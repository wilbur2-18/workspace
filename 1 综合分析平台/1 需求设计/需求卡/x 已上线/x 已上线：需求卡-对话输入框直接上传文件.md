# 对话输入框直接上传文件

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-06-01  
**关联材料**：审计助手对话区；输入框；资源区文件状态；引用文件规则；上传与解析中文件可用性优化

---

## 1. 需求背景

用户在对话中临时需要补充资料时，希望直接在输入框上传文件并继续提问，不必先切到资源区上传，再手动添加到对话。

输入框上传本质上仍复用现有文件上传和解析逻辑，只是在对话输入区提供一个轻量入口；输入框不承载完整上传管理或解析管理。

---

## 2. 目标场景

用户通过输入框附件图标或拖拽添加文件。文件上传完成前，仅作为当前输入框的临时附件；文件上传完成后，立即进入资源树，并在当前输入框中等同于从资源树引用该文件。

用户发送消息时，该文件按引用资源参与本条消息，与从资源树添加到对话的文件遵循同一套引用规则。

---

## 3. 本次做什么

### 3.1 上传入口

- 输入框工具区增加附件上传入口。
- 点击附件图标选择文件。
- 支持将本地文件拖入输入框区域。
- 鼠标悬停附件图标时，展示上传限制说明。

限制说明：

> 支持 PDF、Word、表格、图片、ZIP、MD、TXT、JSON、XML 等格式。单次上传总大小不超过 4GB，文件发送后将保存到资源区并自动引用到当前对话。

### 3.2 上传中临时附件

文件选择后开始上传，并在输入框中展示当前上传文件。

| 状态 | 规则 |
| --- | --- |
| 上传中 | 文件尚未进入资源树；当前消息不可发送；用户可以移除 |
| 上传失败 | 文件未进入资源树；当前消息不可发送；用户可以移除后重新上传 |
| 上传完成 | 文件进入资源树，并自动作为当前输入框引用资源 |

说明：

1. 上传中和上传失败都属于输入框临时态，不进入资源树。
2. 上传完成后，文件进入资源树，成为正式资源。
3. 用户在上传完成前移除文件，不影响资源树。

### 3.3 上传完成后的引用规则

上传完成后的文件与从资源树引用的文件遵循同一套对话引用规则。

| 文件解析状态 | 对话引用规则 |
| --- | --- |
| 排队中 | 允许作为引用发送 |
| 解析中 | 允许作为引用发送 |
| 解析完成 | 允许作为引用发送 |
| 解析失败 | 允许作为引用发送 |

规则：

1. 上传完成后即进入资源树，后续排队、解析、完成、失败都属于资源文件状态。
2. 输入框上传完成的文件，与用户手动从资源树添加到对话的文件保持一致。
3. 引用文件尚未解析完成时，输入区展示引用标签和文件状态；对话需要读取内容时，大模型按需调用 OCR / 解析工具。
4. 本条消息的引用数量和引用来源包含该上传文件。

---

## 4. 本次不做什么

1. 不做输入框内完整上传管理。
2. 不做输入框内解析队列管理；解析状态仍由资源区文件状态承载。
3. 不展示历史上传记录。
4. 不支持从输入框上传文件夹。
5. 不替代资源区上传入口；批量上传、失败处理和资源管理仍在资源区或上传弹窗完成。

---

## 5. 验收口径

1. 用户可以通过输入框附件图标选择文件，也可以将文件拖入输入框区域。
2. 鼠标悬停附件图标时，可以看到支持格式和 4GB 限制说明。
3. 文件上传中时，输入框展示该文件，当前消息不可发送，资源树不新增该文件。
4. 文件上传失败时，当前消息不可发送，资源树不新增该文件，用户可以移除后重新上传。
5. 文件上传完成后，资源树新增该文件，输入框中该文件按引用资源处理。
6. 上传完成后的文件处于排队中、解析中、解析完成或解析失败时，都允许随当前消息发送。
7. 引用文件未解析完成时，对话区展示引用标签和文件状态。
8. 发送消息后，本条消息的引用数量和引用来源包含该上传文件。
9. 用户在上传完成前移除文件，资源树不新增该文件；用户在上传完成后移除输入框引用，不删除资源树文件。
