# 跨工作台引入资料

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-07-02  
**关联材料**：审计助手工作台；资源区文件树；结果树；对话引用资源；工作台权限

---

## 1. 需求背景

审计人员在不同工作台中可能沉淀了可复用的文件、结果和目录结构。当前用户需要先下载再上传，或重新生成结果，才能在当前工作台继续使用，操作成本高，也容易丢失目录关系。

本次新增“引入文件”能力，让用户像在本地文件管理器中复制文件一样，把其他工作台里的文件或结果引入当前工作台。

---

## 2. 目标场景

用户在当前工作台需要复用其他工作台资料时，可以选择有权限访问的工作台，从其中的文件树或结果树选择文件、结果或文件夹，引入到当前工作台资源区，并继续添加到对话、创建任务或作为后续分析资料使用。

---

## 3. 本次做什么

### 3.1 引入入口

资源区“文件”添加菜单和文件夹操作菜单中增加“引入文件”。

打开后进入引入弹窗：

- 弹窗标题为“引入文件”。
- 先选择来源工作台。
- 来源内容分为“文件”和“结果”两个页签。
- 文件和结果均按来源工作台中的目录结构展示。
- 支持按资源名称搜索来源内容。
- 支持选择单个文件、结果文件、文件夹、结果文件夹。
- 已选内容在右侧汇总展示，支持移除单项或清空全部。
- 点击“引入”后，所选内容进入当前工作台资源区。

### 3.2 引入后的展示

引入后的内容作为当前工作台资源展示，不进入结果树。

| 来源对象 | 当前工作台展示 |
| --- | --- |
| 文件 | 资源区文件 |
| 文件夹 | 资源区文件夹，保留子级结构 |
| 结果文件 | 资源区文件 |
| 结果文件夹 | 资源区文件夹，保留子级结构 |

规则：

1. 从文件添加菜单发起时，默认引入到资源区文件树根目录；从某个文件夹发起时，默认引入到该文件夹。
2. 弹窗内不提供目标目录切换，目标位置由发起入口决定。
3. 引入完成后，用户可按现有资源树能力移动、删除、下载或添加到对话。
4. 文件详情中保留来源工作台、来源路径、来源类型和引入时间。

### 3.3 数据规则

引入完成后，在当前工作台生成独立副本。

| 规则 | 说明 |
| --- | --- |
| 内容快照 | 引入后不跟随来源内容更新 |
| 权限影响 | 来源权限被收回后，当前工作台已引入内容仍可使用 |
| 删除影响 | 删除当前工作台内容，不影响来源工作台 |
| 存储统计 | 引入内容计入当前工作台资源存储 |
| 解析状态 | 引入后按当前资源文件规则展示解析状态；可用解析内容随副本带入 |

### 3.4 重名处理

同一目标文件夹下不覆盖已有内容。

- 无重名时，保留原名称。
- 与已有文件或文件夹重名时，自动追加序号，例如“审计资料 (1)”。
- 同批引入多个同名对象时，按引入顺序追加序号。
- 文件夹重名时新建带序号的文件夹，不与已有文件夹合并。

### 3.5 权限与不可用对象

- 只展示当前用户有权限访问的工作台和对象。
- 来源工作台不可访问时，不出现在来源工作台列表中。
- 来源对象不可用、已删除、不存在或未完成生成 / 解析时，默认不进入可引入列表。
- 引入操作需要记录操作人、来源工作台、来源对象和引入时间。

---

## 4. 本次不做什么

1. 不做来源内容实时同步。
2. 不支持反向修改来源工作台内容。
3. 不把引入结果放入当前工作台结果树。
4. 不做数据库表、图谱、知识库的跨工作台引入。
5. 不处理跨网段、跨部署环境的数据迁移。
6. 不新增跨工作台对话直接检索能力。

---

## 5. 验收口径

1. 用户可以从资源区“文件”添加菜单、文件夹更多菜单或文件夹右键菜单打开“引入文件”弹窗。
2. 用户只能看到自己有权限访问的来源工作台和对象。
3. 用户可以在弹窗中切换来源工作台、文件 / 结果页签，并按资源名称搜索来源内容。
4. 用户可以从来源工作台的“文件”或“结果”中选择文件、结果文件或文件夹，右侧已选区展示已选数量并支持移除或清空。
5. 从文件夹入口发起引入后，内容进入该文件夹；从文件添加菜单发起引入后，内容进入资源区文件树根目录。
6. 用户引入文件夹后，当前工作台资源区保留对应目录结构。
7. 来源结果引入后展示在当前工作台资源区，不展示在结果树。
8. 引入内容与来源内容相互独立，后续来源权限变化、来源删除或当前删除都不互相影响。
9. 目标文件夹存在重名时，系统自动追加序号，不覆盖、不合并已有内容。
10. 引入后的资源可继续使用现有添加到对话、移动、下载和删除能力。
