# 资源、结果与任务批量操作

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-05-22  
**关联材料**：三栏式审计助手工作区；左侧资源栏；右侧结果 / 任务区；`DESIGN.md`

---

## 1. 需求背景

审计助手工作台中的资源、结果、任务都存在批量处理诉求。需要在不破坏三栏紧凑布局和单项操作体验的前提下，为当前区域提供独立多选态和批量操作能力。

---

## 2. 目标场景

用户在资源、结果或任务区域中选择多个对象后，可一次性执行添加到对话、下载、删除、中止、重跑等操作。

---

## 3. 本次做什么

### 3.1 多选入口与行交互

- 多选入口位于各区域顶部工具区，按钮顺序为：搜索、排序、多选、刷新、添加类；当前区域无对应操作时跳过。
- 资源、结果、任务分别独立进入多选态，不支持跨栏混选。
- 普通浏览态不展示选择控件，保留对象图标、单项操作和行主行为。
- 进入多选态后，当前区域可选项在左侧独立槽位展示复选框，样式对齐创建任务弹窗中的资源选择树。
- 多选按钮在多选态下保持显示并呈现选中底色；再次点击等同“取消选择”。
- 文件夹主体始终用于展开 / 收起；文件、任务、子任务主体在多选态下可切换选中。
- 选中文件夹等同于选中其下所有可见子文件夹和文件；取消文件夹时同步取消其子级选择。

### 3.2 可选对象与批量操作

**资源**

| 对象 / 状态 | 可批量操作 |
| --- | --- |
| 排队中文件 | 中止、删除 |
| 解析中文件 | 中止、重跑、删除 |
| 失败文件 | 重跑、删除 |
| 已完成文件 | 添加到对话、下载、删除 |
| 资源文件夹 | 添加到对话、打包下载、删除 |
| 数据库表 | 删除 |

**结果**

| 对象 | 可批量操作 |
| --- | --- |
| 结果文件 | 添加到对话、下载、删除 |
| 结果文件夹 | 打包下载、删除 |

结果树只展示结果文件和结果文件夹；生成中、排队中、失败等过程状态属于任务执行层，不作为结果对象参与批量操作。

**任务**

| 对象 / 状态 | 可批量操作 |
| --- | --- |
| 普通任务：排队中 | 中止、删除 |
| 普通任务：运行中 | 中止、删除 |
| 普通任务：失败 | 重跑、删除 |
| 普通任务：完成 | 删除 |
| 跑批子任务：排队中 / 运行中 | 中止、删除 |
| 跑批子任务：失败 | 重跑、删除 |
| 跑批子任务：完成 | 删除 |

任务列表多选仅覆盖普通任务。跑批任务本身不进入任务列表多选态；跑批子任务只在子任务列表内参与多选。

### 3.3 执行规则

- 批量操作按“至少 1 项可执行”展示；执行时处理可执行项，跳过不可执行项。
- 删除、中止、重跑前必须二次确认，确认文案需说明“已选 N 项、将执行 X 项、跳过 Y 项”。
- 跳过原因需可理解，例如“已完成任务无法中止”“当前状态不支持重跑”。
- 批量移动不放入操作条；资源树和结果树通过多选后拖拽到目标文件夹完成移动。

### 3.4 批量操作条

- 进入多选态后，在当前栏顶部工具区下方或当前页签内容下方展示。
- 内容包含：全选框、已选 N 项、取消文字链、常用操作、更多操作。
- “取消选择”放在“已选 N 项”右侧；点击顶部选中态“多选”按钮效果相同。
- 操作条不使用强调底色，仅保留边框线；宽度遵守所在栏内容区 12px 内边距。
- 跑批子任务列表的操作条位于子任务状态页签下方。

---

## 4. 范围边界

1. 图谱等其它资源类型不在本需求范围内。
2. 资源、结果、任务不支持跨栏统一批量操作。
3. 批量操作条不提供“移动”按钮。
4. 不做批量编辑。
5. 跑批任务整体操作沿用行级菜单，不纳入任务列表多选态。

---

## 5. 验收口径

1. 各区域顶部工具区按“搜索、排序、多选、刷新、添加类”顺序展示可用操作。
2. 点击“多选”后，当前区域进入多选态，按钮保持显示并呈现选中底色。
3. 再次点击选中态“多选”按钮或点击“取消选择”，当前区域退出多选态。
4. 多选态下，可选项左侧展示复选框，原对象图标仍保留。
5. 勾选文件夹时，其可见子级同步选中；取消文件夹时其可见子级同步取消。
6. 文件夹主体仍可展开 / 收起；文件、任务、子任务主体可切换选中。
7. 批量操作只展示至少一项可执行的操作，并在确认中说明执行项与跳过项数量。
8. 跑批任务不进入任务列表多选态；跑批子任务只在子任务列表中多选。
