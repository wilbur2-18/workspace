# 用户用量统计

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-07-02  
**关联材料**：系统管理；信息统计；用户管理；组织管理；模型调用记录；系统日志

---

## 1. 需求背景

政府类客户需要了解平台是否被各单位和用户实际使用。首版不做完整运营分析，重点统计大模型 Token 用量，并按组织和用户两个视角展示。

---

## 2. 目标场景

管理员从系统管理进入用量统计页面后，可以按时间和组织范围查看平台使用情况，判断哪些组织在使用、哪些用户使用较多。

---

## 3. 本次做什么

### 3.1 入口与统计范围

用量统计入口放在系统管理模块。页面支持时间范围和统计组织范围两个筛选。

时间范围支持：
- 最近 1 周
- 最近 1 月
- 最近半年

默认展示最近 1 月。

统计组织范围支持从组织树中选择一个组织，组织树支持按名称搜索。默认使用当前管理员可见组织范围；选择组织后，组织用量统计表按该组织范围展示，用户消耗榜单默认按该组织及其下级组织展示。

支持刷新当前统计数据。

### 3.2 顶部汇总

顶部展示当前时间范围内的平台汇总数据，不随统计组织范围切换。

| 指标 | 口径 |
| --- | --- |
| Token 总量 | 当前时间范围内的大模型 Token 消耗，不区分输入 Token 和输出 Token |
| 活跃组织数 | 当前时间范围内产生过模型调用的组织数 |
| 活跃用户数 | 当前时间范围内产生过模型调用的用户数 |
| 调用次数 | 当前时间范围内的大模型调用次数 |

### 3.3 组织用量统计表

组织用量使用树形统计表展示，不使用复杂图表。

| 字段 | 说明 |
| --- | --- |
| 组织单位 | 展示组织名称，支持展开 / 收起下级组织 |
| Token 用量 | 该组织及下级组织的 Token 汇总 |
| 调用次数 | 该组织及下级组织的大模型调用次数 |
| 活跃用户占比 | 该组织及下级组织活跃用户数占当前时间范围活跃用户数的比例 |

规则：

- 默认展示当前管理员可见组织；选择统计组织后，展示所选组织的下一级组织。若所选组织没有下级组织，则展示该组织本身。
- 表格需说明每行统计“本组织及下级组织”的汇总数据。
- 支持展开下级组织。
- 点击组织行后，仅将用户消耗榜单切换为该组织及其下级用户；不改变统计组织范围。
- 用户可属于多个组织；用户归属多个组织时，其 Token 用量、调用次数和活跃用户身份在对应组织及其上级汇总中分别计入。
- 因多组织用户会在多个组织中分别计入，组织表跨组织相加可能大于顶部平台总量；顶部平台总量仍按实际模型调用去重统计。

### 3.4 用户消耗榜单

用户消耗榜单按 Token 用量倒序展示。

| 字段 | 说明 |
| --- | --- |
| 排名 | 当前榜单范围内的用户排名 |
| 用户 | 用户姓名 / 账号 |
| 所属组织 | 用户所属组织；多组织用户展示其命中的组织 |
| Token 用量 | 用户在当前榜单范围内的 Token 消耗 |
| 调用次数 | 用户在当前榜单范围内的大模型调用次数 |

规则：

- 用户榜单按当前统计组织范围展示。
- 从组织用量统计表点击某个组织后，用户榜单切换为该组织及下级用户；用户可以取消选中，恢复为统计组织范围。
- 用户榜单支持分页，并可切换每页展示数量。
- 用户属于多个组织时，展示其在当前榜单范围内命中的组织。

### 3.5 导出入口

组织用量统计表和用户消耗榜单分别提供导出入口；当前原型先预留入口并给出操作提示，不做真实文件导出。

规则：

- 组织用量统计导出入口对应当前时间范围和统计组织范围。
- 用户消耗榜单导出入口对应当前时间范围和当前用户榜单范围。
- 后续接入真实导出时，组织导出不受展开 / 收起状态影响，用户导出不受分页状态影响。

| 导出入口 | 内容 |
| --- | --- |
| 组织用量统计导出 | 当前统计组织范围内的组织单位、Token 用量、调用次数、活跃用户占比 |
| 用户消耗榜单导出 | 当前用户榜单范围内的用户、所属组织、Token 用量、调用次数 |

---

## 4. 本次不做什么

1. 不统计资源上传量、任务数、结果数等功能使用明细。
2. 不把创建技能数作为首版核心指标。
3. 不做复杂趋势图、大屏或多维运营分析。
4. 不做费用结算、额度扣减或账单管理。
5. 不按输入 Token、输出 Token 拆分统计。
6. 不做整页统一导出。

---

## 5. 验收口径

1. 管理员可以从系统管理进入用量统计，并切换时间范围和统计组织范围。
2. 顶部汇总按当前时间范围展示平台级统计，不随统计组织范围切换。
3. 顶部可以看到 Token 总量、活跃组织数、活跃用户数、调用次数，Token 总量不区分输入和输出。
4. 组织用量以树形表格展示，组织行统计本组织及下级组织的汇总用量，并展示活跃用户占比。
5. 多组织用户的 Token 用量、调用次数和活跃用户身份在对应组织及其上级汇总中分别计入。
6. 用户可以在统计组织范围选择中按组织名称搜索并选择组织。
7. 点击组织行后，用户榜单切换为该组织及其下级用户；取消选中后恢复为统计组织范围。
8. 用户榜单支持分页和每页数量切换。
9. 用户可以刷新统计数据。
10. 用户可以分别看到组织用量统计和用户消耗榜单的导出入口；当前原型点击后提示导出入口已预留。
