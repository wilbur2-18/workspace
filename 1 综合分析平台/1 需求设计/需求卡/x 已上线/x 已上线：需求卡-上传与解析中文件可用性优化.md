# 上传与解析中文件可用性优化

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-06-01  
**关联材料**：审计助手工作台；上传文件弹窗；资源区状态入口；对话引用资料；资料解析状态

---

## 1. 需求背景

审计资料上传后会经历上传、排队、解析、失败或完成等状态。原型重点模拟用户在等待期间继续使用工作台，并清楚区分上传会话、资源入库和解析状态。

对话支持大模型按需调用 OCR / 解析工具。未完成解析文件可以作为对话引用，由系统在需要读取内容时发起工具处理，用户只需要关注文件处理状态和对话结果。

---

## 2. 目标场景

用户在工作台上传文件后，文件先进入上传弹窗的待上传列表；点击开始上传后进入上传中；上传成功后从弹窗移除并进入资源区排队解析。解析未完成前，用户可以在资源区查看文件状态，也可以把文件添加到对话；如果对话需要读取文件内容，大模型按需调用 OCR / 解析工具。

---

## 3. 本次做什么

### 3.1 上传文件弹窗

上传弹窗标题为“上传文件”。

| 状态 | 展示与操作 |
| --- | --- |
| 零文件 | 单栏上传入口，展示支持格式、ZIP、数量和大小限制说明 |
| 待上传 | 展示在当前上传会话列表，可移除，可点击「开始上传（N）」进入上传中 |
| 上传中 | 展示上传进度，可取消上传；关闭弹窗不取消上传 |
| 上传失败 | 留在弹窗中，展示失败原因，可重试上传或移除 |

规则：

1. 有文件后弹窗切换为双栏：左侧轻量上传入口和上传说明，右侧当前上传会话列表。
2. 上传成功的文件立即从弹窗移除，并进入资源区排队解析。
3. 上传中允许继续添加文件，新文件进入待上传，需要再次点击底部按钮才会上传。
4. 「清空」只清除待上传文件，不影响上传中和上传失败文件。
5. 底部按钮为「关闭」和「开始上传（N）」；存在上传中或失败但无待上传文件时，不展示主按钮。
6. 当前原型以流程模拟为主，点击上传区域生成模拟文件；真实文件选择、真实拖拽解析和浏览器文件 IO 不作为本轮原型验收项。

### 3.2 上传与解析状态

1. 页面顶部仅在存在上传中文件时展示 uploading 提示，文案为“X 个文件正在上传，请勿关闭或刷新页面”。
2. 点击顶部 uploading 提示回到当前上传弹窗，并保留本次上传目标文件夹。
3. 上传中刷新或关闭页面时触发离开提醒。
4. 仅剩上传失败项时，不展示顶部 uploading 提示。
5. 存在上传失败且弹窗关闭时，资源区「添加」按钮展示失败数量角标。
6. 资源区只承接已入库文件，状态入口展示排队中、解析中、失败及数量，不展示上传中。
7. 点击资源区状态入口后，只展示对应状态的已入库文件；返回全部后恢复文件树。
8. 上传成功后，文件在资源区首个状态为排队中，并在原型中继续模拟进入解析中、完成。

### 3.3 解析中文件引用优化

| 场景 | 规则 |
| --- | --- |
| 资源区存在排队中、解析中或失败文件 | 展示状态入口和数量 |
| 用户在对话输入区引用未完成解析文件 | 允许添加到对话；输入区展示引用标签和文件状态 |
| 大模型需要读取文件内容 | 可主动调用 OCR / 解析工具；工具执行过程按现有对话工具调用交互展示 |
| 用户预览未完成解析文件 | 原始文件可预览时允许打开；OCR 结果未生成时展示空态或暂无内容 |

说明：

1. 排队中、解析中、失败文件都可以作为结构化引用发送。
2. 文件解析状态在资源区和引用标签中展示，用于告知处理进度。
3. 解析失败文件支持提交给对话工具尝试处理；如工具调用失败，再在工具执行结果中反馈失败原因。

### 3.4 文件操作与批量操作

资料文件行级操作按状态展示：

| 状态 | 主动作 | 更多菜单 |
| --- | --- | --- |
| 排队中 | 中止 | 添加到对话、下载、重命名、删除 |
| 解析中 | 添加到对话 | 中止、下载、重命名、删除 |
| 失败 | 重跑 | 添加到对话、下载、重命名、删除 |
| 已完成 | 添加到对话 | 下载、重命名、删除 |

批量操作规则：

1. 资源区和上传弹窗的批量操作互相独立，不跨区域混选。
2. 批量操作按“所选项中至少一项支持即展示”处理；执行时只处理支持项，并反馈已处理和跳过数量。
3. 批量条最多外放 2 个业务动作，其余进入“更多”。
4. 资源区动作排序按覆盖数量优先；同覆盖数下按中止、重跑、添加到对话、下载、删除排序。
5. 上传弹窗批量动作按上传会话状态提供：待上传支持上传/移除，上传中支持取消上传，上传失败支持重试上传/移除。
6. 行内操作区保持“更多在左，核心操作在右”。
7. 菜单图标仅保留给关键动作：添加到对话、上传文件、新建文件夹、删除；下载、重命名、中止、重跑等常规动作使用纯文字。

---

## 4. 本次不做什么

1. 不新增完整上传历史中心。
2. 不把上传进度放入资源区或右侧任务区。
3. 不调整 ZIP 解压、自动 OCR 和资料解析规则。
4. 不新增压缩包内容预览或上传前选择部分文件能力。
5. 不改变任务资源选择和任务执行规则。
6. 不新增 OCR / 解析工具的配置项。
7. 不把真实文件选择、真实拖拽上传和网络上传作为当前原型验收项。

---

## 5. 验收口径

1. 打开上传弹窗时，零文件态展示单栏上传入口、支持格式、ZIP、数量和大小限制说明。
2. 点击上传区域后，原型生成待上传文件，弹窗切换为双栏并展示上传会话列表。
3. 点击「开始上传（N）」后，待上传文件进入上传中；关闭弹窗不取消上传。
4. 上传中顶部展示 uploading 提示，点击后回到上传弹窗。
5. 上传成功文件从弹窗移除，并在资源区以排队中状态出现。
6. 上传失败文件留在弹窗中，可重试上传或移除；弹窗关闭后「添加」按钮展示失败数量角标。
7. 资源区状态入口仅展示排队中、解析中、失败，不展示上传中。
8. 点击任一资源区状态入口后，资源区只展示对应状态的已入库文件。
9. 上传中刷新或关闭页面时触发离开提醒。
10. 资源区存在未完成解析文件时，展示状态入口和数量。
11. 用户引用排队中、解析中或失败文件时，输入区展示引用标签和文件状态。
12. 大模型需要读取未完成解析文件内容时，可以在对话中调用 OCR / 解析工具，并展示工具调用过程。
13. 用户预览未完成解析文件时，原始文件可预览则允许打开；OCR 结果未生成时展示空态或暂无内容。
14. 文件树、状态列表、右键菜单和详情入口中，同一资源状态文件的可用操作口径一致。
15. 资源区与上传弹窗批量操作均按最大集合展示，执行后反馈已处理项数和跳过项数。
16. 行内操作顺序为“更多在左，核心操作在右”。
17. 常规菜单动作不展示图标，关键动作保留图标。
18. 上传中继续添加文件后，新文件保持待上传，需再次点击底部主按钮才开始上传。
19. 当前上传会话全部成功并清空后，toast「已全部上传」并自动关闭弹窗。

## 关键决策

| 决策点 | 结论 |
| --- | --- |
| 原型范围 | 以流程模拟为主，不验收真实文件 IO |
| 上传状态承接 | 待上传、上传中、上传失败由上传弹窗承接 |
| 资源区状态承接 | 只承接已入库文件，状态入口为排队中、解析中、失败 |
| 顶部提示 | 只在存在上传中会话时展示 |
| 弹窗关闭语义 | 「关闭」只关弹窗，不取消上传中会话 |
| 全部成功 | toast + 自动关闭弹窗 |
| 失败外部提醒 | 「添加」按钮角标展示上传失败数量 |
| 解析中文件引用 | 可正常引用；大模型按需调用 OCR / 解析工具 |
| 批量条上限 | 最多外放 2 个业务动作，其余进入“更多” |
| 菜单图标 | 关键动作保留图标，常规动作纯文字 |
