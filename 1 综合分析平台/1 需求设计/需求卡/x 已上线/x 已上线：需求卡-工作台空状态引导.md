# 工作台空状态引导

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-06-01  
**关联材料**：审计助手三栏工作台；资源区；技能区；对话区；任务区；结果区

---

## 1. 需求背景

工作台首次进入或局部内容为空时，需要让用户快速知道下一步从哪里开始。当前原型口径为：区域内保留极简占位和就近入口，对话区只在新会话时展示轻量引导卡。

本卡以当前原型实现为基准，收敛原先待确认问题，不再要求额外的示例问题填入输入框。

---

## 2. 目标场景

用户进入审计助手工作台后，可以在空工作台、资源已就绪、已有技能等状态下快速选择下一步；发送第一条消息后，对话区进入正常消息流。

---

## 3. 本次做什么

### 3.1 区域空状态

| 区域 | 原型空态 | 操作口径 |
| --- | --- | --- |
| 文件资源 | 文件树无内容时展示轻量空态 | 上传入口在文件标题右侧「添加」菜单 |
| 数据库表 | 只展示轻量占位图，不展示提示文字 | 复用添加库表入口 |
| 数据图谱 | 只展示轻量占位图，不展示提示文字 | 复用添加图谱入口 |
| 知识库 | 展示轻量空态，占位说明“知识库能力暂未开放，当前仅展示占位信息。” | 本轮不提供关联知识库入口 |
| 技能 | 展示“添加技能 / 为大模型注入专业的审计思路” | 提供创建技能、引用技能 |
| 任务 | 无任务时展示轻量空态占位 | 创建任务沿用现有入口和对话引导 |
| 结果 | 无结果时展示轻量空态占位 | 不展示按钮 |

展示规则：

1. 区域空态只表达当前区域为空，不放长业务说明。
2. 空态入口复用当前区域已有入口，不新增专属流程。
3. 多个区域同时为空时，入口保持轻量样式。
4. 解析中、排队中、执行中等过程状态优先于空态。

### 3.2 对话区新会话引导

对话区引导只在当前工作台没有消息时展示。

| 当前状态 | 标题 | 引导卡 |
| --- | --- | --- |
| 无任何资源 | 你好，本次审计从哪里开始？ | 审文件：上传资料或压缩包；查数据：添加数据库表；查人或关系：配置数据图谱 |
| 有资源，无技能 | 资源已就绪，接下来想怎么审？ | 直接提问：围绕当前资料追问、核对、总结；配置技能：创建或引用审计方法（技能） |
| 有资源，有技能 | 资源已就绪，接下来想怎么审？ | 直接提问：围绕当前资料追问、核对、总结；配置技能：创建或引用审计方法（技能）；创建任务：重复执行技能，批量审计 |

规则：

1. 无资源只展示 3 个资源切入卡，不展示知识库入口。
2. 有资源时不展示示例问题和结果入口。
3. 配置技能始终展示；创建任务仅在已有技能时展示。
4. 引导卡只触发现有流程，不新增独立空态流程。
5. 引导卡图标复用现有业务列表图标，不使用临时或新增图标。

---

## 4. 本次不做什么

1. 不新增资源、技能、任务、结果流程。
2. 不新增空态专属入口。
3. 不新增知识库关联入口。
4. 不做示例问题点击填入输入框。
5. 不定义移动端适配。

---

## 5. 验收口径

1. 文件、数据库表、数据图谱、知识库为空时均展示轻量空态；数据库表和数据图谱只展示占位图，不展示提示文字。
2. 技能为空时展示技能空态，并提供创建技能、引用技能入口。
3. 任务为空时只展示轻量空态；结果为空时只展示轻量空态且不展示按钮。
4. 新会话且无资源时，标题为“你好，本次审计从哪里开始？”，展示“审文件 / 查数据 / 查人或关系”3 张卡。
5. 点击“审文件 / 查数据 / 查人或关系”分别进入上传资料、添加数据库表、配置数据图谱流程。
6. 新会话且有资源无技能时，标题为“资源已就绪，接下来想怎么审？”，只展示“直接提问 / 配置技能”。
7. 新会话且有资源有技能时，展示“直接提问 / 配置技能 / 创建任务”。
8. 点击“直接提问”聚焦输入框；点击“配置技能”切到技能区；点击“创建任务”打开创建任务流程。
9. 引导卡图标与现有业务列表图标一致，不出现临时技能图标或任务类型不一致的图标。
10. 用户发送第一条消息后，引导消失；解析中、排队中、执行中状态不被空态覆盖。

---

## 关键决策

| 决策点 | 结论 |
| --- | --- |
| 空态入口 | 复用现有入口，不新增专属流程 |
| 资源入口 | 原型只提供审文件、查数据、查人或关系 3 个资源切入 |
| 知识库 | 需要轻量空态占位，但不进入本轮空态入口 |
| 对话示例 | 当前原型不做示例问题填入输入框 |
| 图标口径 | 引导卡复用现有业务图标，不新增临时图标 |
| 任务入口 | 仅在已有技能时展示；技能、任务都不是必备前置流程 |
| 结果入口 | 新会话引导不展示结果卡 |
| 引导消失时机 | 发送第一条消息后消失 |
| 状态优先级 | 过程状态优先于空态 |
