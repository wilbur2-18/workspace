# 任务资源配置支持结果与文件树选择

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-05-20  
**关联材料**：`综合分析平台 20260520/` 创建任务弹窗、左侧资源树、右侧结果树

---

## 1. 需求背景

当前创建任务时，任务资源主要从文件、数据库、图谱中选择，文件资源以列表方式展示；但实际审计分析中，任务上下文也可能来自前序分析结果，且文件和结果本身已经在工作台中按树形结构组织。

本次优化重点是让任务资源配置复用已有的文件树和结果树，支持按文件夹批量选择，并补齐各类资源的全选 / 取消全选能力，降低资源较多时的选择成本。

---

## 2. 目标场景

审计人员创建单次任务或跑批任务时，可以选择文件、结果、数据库、图谱作为上下文资源；当文件或结果按文件夹归档时，可以直接选择文件夹；当资源较多时，可以基于当前搜索结果进行全选或取消全选。

---

## 3. 本次做什么

### 3.1 资源来源扩展

创建任务的“选择资源”步骤支持以下资源来源：

| 资源类型 | 展示方式 | 选择方式 |
| --- | --- | --- |
| 文件 | 按左侧文件树展示 | 支持选择文件、文件夹 |
| 结果 | 按右侧结果树展示 | 支持选择结果、结果文件夹 |
| 数据库 | 保持现有列表展示 | 支持选择单个或多个数据库资源 |
| 图谱 | 保持现有列表展示 | 支持选择单个或多个图谱资源 |

说明：

- “结果”作为任务输入资源，不等同于“结果输出位置”。
- 单次任务和跑批任务都支持选择结果资源作为上下文。
- 文件夹 / 结果文件夹被选中后，已选区展示文件夹本身，不展开为每一个文件或结果。
- 提交任务时，系统按文件夹关系解析其下符合条件的文件或结果，重复命中的资源只计算一次。

### 3.2 批量选择规则

各类资源支持全选 / 取消全选。

| 操作 | 规则 |
| --- | --- |
| 全选 | 选择当前搜索结果范围内的可选资源 |
| 取消全选 | 移除当前搜索结果范围内已选资源 |
| 清空 | 清空全部已选资源 |

说明：

- 未输入搜索条件时，当前搜索结果等同于当前资源类型下全部可选资源。
- 全选只作用于当前资源类型，不影响其他资源类型。
- 文件和结果只选择可被任务引用的资源；解析中、失败、不可用、无权限或不可读取的资源不进入可选范围。
- 全选不会重复加入已选资源。

---

## 4. 本次不做什么

1. 不调整工作台左侧文件树和右侧结果树本身的组织规则。
2. 不改变文件解析、结果生成、任务执行和跑批调度规则。
3. 不新增资源筛选、排序、权限配置或高级搜索能力。
4. 不把“结果输出位置”和“结果资源选择”合并为同一个字段。
5. 不要求已选区展开展示文件夹下的全部文件或结果。

---

## 5. 验收口径

1. 创建任务选择资源时，可以看到文件、结果、数据库、图谱四类资源来源。
2. 文件资源按文件树展示，支持选择文件或文件夹。
3. 结果资源按结果树展示，支持选择结果或结果文件夹。
4. 用户选择文件夹或结果文件夹后，已选区展示对应文件夹，不展开明细。
5. 用户可以对当前搜索结果范围内的资源执行全选 / 取消全选，且不影响其他资源类型。
6. 提交任务后，任务详情“引用资源”可以展示本次配置的文件、结果、数据库、图谱及对应文件夹资源。

---

## 关键决策

| 决策点 | 结论 |
| --- | --- |
| 结果树文件夹选择 | 支持 |
| 已选区展示方式 | 展示用户实际选择的文件夹，不展开明细 |
| 跑批任务上下文 | 允许选择结果资源 |
| 全选范围 | 按当前搜索结果生效 |
