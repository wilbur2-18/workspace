# 跑批任务

**产品**：综合分析平台  
**状态**：已上线  
**更新**：2026-05-15

## 1. 需求背景

审计场景中经常需要对成百上千条数据逐行执行同一个技能，例如批量查询企业工商信息。现有单次任务只能一条一条创建，无法支撑高频批量执行；同时，跑批任务会产生多个子任务，任务列表和任务详情也需要对应调整。

## 2. 目标场景

审计用户手头有一份 500 家企业名单，希望上传 Excel 文件，选择技能后一次性提交。系统按文件中的每一行创建子任务，后台逐行调度执行，用户可以在任务列表中查看整体进度、下钻查看子任务，并对失败项进行重跑。

## 3. 本次做什么

### 3.1 创建任务

基于现有“创建任务”弹窗改为步骤引导式。

| 步骤 | 单次任务 | 跑批任务 |
| --- | --- | --- |
| 执行方式配置 | 输入任务名称；选择技能；系统生成任务指令，支持人工修改 | 输入任务名称；选择技能；上传 .xlsx 数据源文件；预览前 10 行；选择标识列；系统生成任务指令，支持人工修改 |
| 选择任务资源 | 可从文件、数据图谱、数据库中选择多个资源 | 可从文件、数据图谱、数据库中选择多个资源 |
| 创建任务 | 创建 1 个任务 | 创建 1 个父任务和若干子任务 |

说明：

- 跑批任务按数据源文件逐行生成子任务。
- 标识列用于区分每个子任务对应的数据行。
- 数据源文件仅支持 `.xlsx`。

### 3.2 任务列表

任务列表兼容单次任务和跑批任务。

| 对象 | 展示与操作 |
| --- | --- |
| 跑批父任务 | 展示整体进度；支持下钻进入子任务列表 |
| 子任务列表 | 顶部展示状态统计页签；点击状态可筛选子任务 |
| 任务详情 | 根据任务类型展示对应配置和任务指令 |

### 3.3 任务操作

| 对象 | 操作 | 规则 |
| --- | --- | --- |
| 跑批父任务 | 中止 | 中止所有排队中和运行中的子任务，中止后子任务进入失败 |
| 跑批父任务 | 全部重跑 | 重跑全部子任务 |
| 跑批父任务 | 仅失败重跑 | 仅重跑失败子任务 |
| 跑批父任务 | 删除 | 删除任务及全部子任务，包含结果 |
| 子任务 - 排队中 | 中止 | 中止后进入失败 |
| 子任务 - 运行中 | 中止 | 中止后进入失败 |
| 子任务 - 成功 | 删除 | 删除该子任务及结果 |
| 子任务 - 失败 | 重跑、删除 | 重跑后进入排队中，再进入运行中 |

### 3.4 打包下载

结果树中的文件夹增加“打包下载”操作，可将文件夹下的目录和文件打包为 zip 下载。

- 下载文件默认为 Markdown 格式。
- 支持保留层级打包。
- 支持剔除层级打包。

## 4. 本次不做什么

1. 不做数据源文件在线编辑。
2. 不支持 CSV 或其他格式作为数据源文件。
3. 不支持基于资源或结果作为跑批数据源。
4. 不做批量执行中的人工暂停或人工干预。
5. 不做子任务执行优先级配置。

## 5. 验收口径

1. 用户可以选择创建单次任务或跑批任务。
2. 跑批任务仅支持上传 `.xlsx` 数据源文件。
3. 上传数据源后可以预览前 10 行，并选择标识列。
4. 创建跑批任务后，系统生成 1 个父任务和若干子任务。
5. 跑批父任务可以下钻查看子任务列表。
6. 子任务列表可以按状态统计和筛选。
7. 父任务支持中止、全部重跑、仅失败重跑、删除。
8. 子任务按排队中、运行中、成功、失败展示对应操作。
9. 结果文件夹支持按保留层级或剔除层级打包下载。
