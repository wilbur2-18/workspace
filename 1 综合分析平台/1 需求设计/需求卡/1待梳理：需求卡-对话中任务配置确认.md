# 对话中任务配置确认

**产品**：综合分析平台  
**状态**：待梳理  
**更新**：2026-05-23  
**关联材料**：对话助手；创建任务；跑批任务；打包下载任务；任务配置

---

## 1. 需求背景

助手可以根据用户在对话中的描述生成任务配置，并准备创建单次任务、跑批任务或打包下载任务。和删除、移动这类操作不同，任务类确认不是简单判断“过不过”，而是需要用户判断配置是否正确，必要时快速修改关键字段。

如果只让用户在对话里反复说“这里不对、再改一下”，会降低效率；但如果一开始就展示完整任务创建表单，又会打断对话式流程。因此需要在对话中提供轻量的任务配置确认，并保留必要的手工调整入口。

---

## 2. 目标场景

用户通过对话让助手创建任务时，助手先生成任务配置摘要。用户可以直接确认创建，也可以进入配置编辑态修改关键字段后再提交。

---

## 3. 本次做什么

### 3.1 触发范围

| 类型 | 触发规则 | 示例 |
| --- | --- | --- |
| 单次任务 | 助手根据对话生成一次性分析任务配置 | 基于当前资料创建分析任务 |
| 跑批任务 | 助手根据资源、表格或标识列生成批量执行配置 | 基于表格每一行生成子任务 |
| 打包下载任务 | 助手根据用户选择生成后台打包配置 | 批量下载结果并选择是否 MD 转 PDF |
| 后续异步任务 | 本质是提交后台任务，且需要用户确认关键配置 | 打包上传任务、补充 OCR 任务 |

### 3.2 配置摘要态

助手先展示任务配置摘要，让用户快速判断配置是否可执行。

| 内容 | 规则 |
| --- | --- |
| 任务名称 | 展示助手生成的任务名称 |
| 任务类型 | 展示单次任务、跑批任务、打包下载任务等 |
| 输入范围 | 展示资源、结果、文件夹、数据库表等范围 |
| 使用技能 / 配置 | 展示技能名称、当前配置或关键策略 |
| 输出位置 | 展示结果保存位置或产物入口 |
| 关键参数 | 展示跑批标识列、下载格式、是否转 PDF、OCR 范围等 |
| 操作按钮 | “创建任务”“调整配置”“取消” |

说明：

- 摘要态以扫读为主，不直接展示完整表单。
- 如果配置存在缺失或冲突，应提示用户先调整，不能直接创建。

### 3.3 配置编辑态

用户点击“调整配置”后，进入可编辑配置态。该状态用于快速修正关键字段，不替代完整任务创建器。

| 可编辑内容 | 规则 |
| --- | --- |
| 任务名称 | 支持手工修改 |
| 输入范围 | 支持增删资源、结果或文件夹 |
| 使用技能 | 支持切换技能或确认当前技能配置 |
| 输出位置 | 支持修改结果保存位置 |
| 任务指令 | 支持编辑助手生成的任务指令 |
| 跑批关键字段 | 支持调整标识列、子任务命名等关键跑批字段 |
| 打包 / OCR 参数 | 支持调整下载格式、是否转 PDF、OCR 范围等关键选项 |

说明：

- 用户也可以继续在对话中说“把任务名改成...”“资源换成...”，由助手更新配置摘要。
- 第一版只编辑关键字段，不做所有高级配置。
- 编辑后回到摘要态，由用户最终点击“创建任务”。

### 3.4 提交流程

1. 助手生成任务配置摘要。
2. 用户确认无误，点击“创建任务”。
3. 用户需要修改，点击“调整配置”或继续用对话补充修改。
4. 配置修改后再次展示摘要。
5. 用户确认后创建任务，并在对话中反馈任务创建结果。

---

## 4. 本次不做什么

1. 不把完整任务创建器全部搬进对话卡片。
2. 不做任务高级配置的完整编辑能力。
3. 不做多人审批或任务审批流。
4. 不改变任务创建后的状态流转、排队、运行和失败规则。
5. 不处理对象不唯一的选择问题；对象歧义先进入“对话中歧义选择”。

---

## 5. 验收口径

1. 助手准备创建任务前，会先展示任务配置摘要，不直接提交任务。
2. 用户可以在摘要中看到任务名称、任务类型、输入范围、使用技能、输出位置和关键参数。
3. 用户点击“创建任务”后，系统按该配置创建任务并反馈结果。
4. 用户点击“调整配置”后，可以修改关键字段，并在修改后重新确认。
5. 配置缺失或冲突时，系统不允许直接创建任务，并提示需要调整的内容。
6. 用户继续通过对话修改配置后，确认卡内容同步更新。
7. 对象或参数存在多个候选时，先进入歧义选择，再回到任务配置确认。
