# 技能版本回退

**产品**：综合分析平台  
**状态**：待开发  
**更新**：2026-05-14  
**原始需求**：[[20260429-技能版本快照与恢复]]

## 1. 需求背景

用户在“我的技能”中导入或编辑技能配置后，可能需要保留阶段性版本；当后续修改不符合预期时，需要能够查看历史版本并回退到指定版本。

本次需求通过“快照”方式管理技能版本，避免用户只能依赖手工备份 JSON。

## 2. 目标场景

用户从本地导入 JSON 技能到“我的技能”，编辑配置后创建快照。后续发现当前配置不合适时，可以进入历史版本查看详情，并将目标历史版本恢复为当前技能配置。

## 3. 本次做什么

### 3.1 创建快照

在“技能详情 - 技能配置”中，用户可以将当前技能配置保存为一个历史版本。

| 字段 | 规则 |
| --- | --- |
| 版本号 | 必填，不可重复 |
| 描述 | 必填，用于说明本次快照内容 |
| 快照内容 | 保存当前技能配置 |

### 3.2 查看历史版本

用户可以在技能详情中查看该技能的历史版本列表，并查看单个历史版本的配置详情。

### 3.3 回退到历史版本

用户选择某个历史版本进行回退时，系统需要二次确认：

- 用户确认是否先将当前配置创建为快照。
- 如果选择创建快照，则先保存当前配置，再恢复目标历史版本。
- 如果选择不创建快照，则直接用目标历史版本覆盖当前配置。

## 4. 本次不做什么

1. 工作台中引用的技能不支持快照和版本回退。
2. 历史版本不支持导出。
3. 不做不同历史版本之间的差异对比。
4. 不支持多个技能之间互相恢复版本。

## 5. 验收口径

1. 用户可以在技能配置页创建快照。
2. 创建快照时必须填写版本号和描述。
3. 重复版本号不能保存。
4. 用户可以查看历史版本详情。
5. 用户回退历史版本前，会看到二次确认。
6. 用户选择“先快照再回退”时，当前配置会先保存为新快照，再恢复目标版本。
7. 回退完成后，当前技能配置被目标历史版本覆盖。
