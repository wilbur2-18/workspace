# 知识库接入与对话引用

**产品**：综合分析平台  
**状态**：待梳理  
**更新**：2026-05-29  
**关联材料**：审计助手资源区；知识库抽屉；数据图谱添加弹窗；数据库表添加弹窗；对话引用资源

---

## 1. 需求背景

当前工作台资源区已有文件、数据库表、数据图谱和知识库分组，但知识库仍为占位状态。后端已通过外部知识库平台完成数据打通，不需要用户在综合分析平台内配置连接。

本次需求重点是让用户选择本次对话需要使用的知识库，并在对话中作为可引用资源使用。

---

## 2. 目标场景

审计人员进入工作台后，可以从已有外部知识库中选择一个或多个知识库加入当前工作台，并在对话中引用。大模型回答时，可结合用户选定的知识库进行制度、政策、规范或历史资料检索。

---

## 3. 本次做什么

### 3.1 知识库资源区

- 左侧资源区保留“知识库”分组。
- 知识库分组展示已加入当前工作台的知识库。
- 知识库分组增加“添加知识库”入口，交互参考“添加数据图谱”。
- 支持搜索已加入的知识库。
- 知识库条目支持添加到对话、查看详情、移除。

### 3.2 添加知识库

打开“添加知识库”弹窗后，展示外部知识库平台已授权给当前用户的知识库列表。

建议列表信息：

| 信息 | 说明 |
| --- | --- |
| 知识库名称 | 用户识别知识库用途 |
| 简介 | 展示知识库内容范围 |
| 来源 / 范围 | 如组织级、项目级、个人可用等 |
| 更新时间 | 帮助用户判断内容新鲜度 |
| 状态 | 可用、已添加、无权限或不可用 |

规则：

1. 用户可一次选择多个知识库。
2. 已加入当前工作台的知识库展示“已添加”，不可重复添加。
3. 无权限或不可用知识库不可选择，但可展示原因。
4. 点击“添加”后，知识库进入左侧知识库分组。

### 3.3 对话中使用知识库

- 知识库条目支持“添加到对话”。
- 添加后，输入框引用区展示知识库引用标签，样式与数据库表、图谱引用保持一致。
- 用户发送消息后，大模型在本轮问题中可使用已引用知识库。
- 未引用知识库时，不默认使用全部知识库，避免检索范围过大。

### 3.4 知识库详情

知识库详情以只读方式展示基础信息。

建议包含：

- 知识库名称。
- 简介 / 内容范围。
- 来源平台。
- 更新时间。
- 可用状态。
- 可检索范围说明。

---

## 4. 本次不做什么

1. 不在综合分析平台内创建、编辑、删除外部知识库。
2. 不做知识库连接配置、账号配置或同步配置。
3. 不做知识库内容全文预览。
4. 不做知识库权限管理。
5. 不默认把所有知识库加入每次对话。
6. 不改变文件、数据库表、数据图谱已有添加和引用逻辑。

---

## 5. 验收口径

1. 资源区“知识库”分组不再展示“能力暂未开放”占位。
2. 用户可以打开“添加知识库”弹窗，并看到可用知识库列表。
3. 用户选择知识库并点击添加后，知识库出现在左侧知识库分组。
4. 已添加知识库不可重复添加。
5. 用户可以将知识库添加到对话输入框引用区。
6. 发送消息后，本轮对话使用已引用知识库作为可检索资源。
7. 用户移除知识库后，该知识库不再出现在当前工作台知识库分组中。
8. 无权限或不可用知识库不能被添加，并展示不可用原因。

## 待确认问题

| 问题 | 影响 |
| --- | --- |
| 知识库是加入当前工作台后再添加到对话，还是可从弹窗直接加入当前对话 | 影响是否完全复用图谱交互 |
| 添加到工作台的知识库是否在同一工作台内持久保留 | 影响工作台资源保存口径 |
| 大模型是否只使用输入框显式引用的知识库 | 影响默认检索范围和回答可控性 |
| 知识库详情是否需要展示文档数量、分组、标签等统计信息 | 影响弹窗信息密度 |
