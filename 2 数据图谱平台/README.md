# 数据图谱平台

数据图谱平台用于沉淀图谱查询、图谱管理、图谱工作台等相关产品资料、需求池、原型和历史材料。

## 目录角色

| 目录 | 作用 |
| --- | --- |
| `0 产品文档` | 产品定位、方向性方案、产品地图和对外材料。 |
| `1 需求池` | 尚未进入设计或开发的需求、想法和待收敛问题。 |
| `2 需求设计` | 已进入设计阶段的需求说明、高保真原型、设计图和版本说明。 |
| `x 历史备份` | 历史原型、资料备份包和不再作为当前入口的材料。 |
| `x 杂七杂八` | 临时分析、架构梳理、材料汇总和一次性讨论产物。按事项独立建文件夹。 |

## 归类边界

- 需求想法先进入 `1 需求池`；已明确要做原型或交互方案时，再进入 `2 需求设计`。
- 原型目录内的修改，以该原型目录自己的 README / AGENTS 为准。
- 与需求池、需求设计或正式产品文档无直接关系的临时材料，放入 `x 杂七杂八/<事项>/`。
- `x 杂七杂八` 下不要直接散放文件；每个事项建立独立文件夹。
