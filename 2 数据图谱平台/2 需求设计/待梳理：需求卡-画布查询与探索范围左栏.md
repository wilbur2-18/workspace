# 画布查询模型、查询范围左栏与顶栏显示筛选

**产品**：数据图谱平台  
**状态**：待梳理  
**更新**：2026-05-21  
**关联材料**：图查询画布高保真 `2 需求设计/数据图谱平台 20260520/`（`graph-workbench.js`、`graph-query.css`）、`2待开发：需求卡-图查询画布交互重构.md`（左侧与顶栏筛选以本卡为准）

---

## 1. 需求背景

当前画布左栏（`graph-canvas-query-panel`）主要展示「当前查询结果摘要 + 模板条件 + 多条件过滤」，更像一次查询的说明书，与用户真实研判流程不匹配：

1. 母模板查回的关系往往**全量、未过滤**，分析师需在海量关系中手工收窄，效率低。
2. 研判是**持续性行为**：多次换模板、过滤、拓展、路径分析等，步骤不固定；现有左栏无法记录过程。
3. 需明确：画布 = 持续 **查询 Session**；**改口径**的过滤绑步骤与勾选；**不改口径**的显示控制放顶栏，画布/列表共用。

本次梳理：**查询 Session / 查询步骤 / 步骤模板 / 步骤过滤 / 顶栏显示筛选（类型 + 高级）/ 顶栏查找 / 列表列排序 / 查询范围左栏（两块）**。不改变工作台左 rail 定位。

---

## 2. 目标场景

审计 / 研判人员在**同一次查询 Session**中：多步查询 → 步骤过滤 → 在**当前查看**上按类型与属性收窄 → 列表核查与导出。需要：

- 左栏理解**查了哪几步、每步怎么查**（改口径）；
- 顶栏固定配置**怎么看当前结果**（不改口径）：类型筛选、高级筛选、查找定位；
- 列表模式在表头排序，在顶栏查找，**无独立类型下拉**；
- 底栏图例与顶栏类型筛选**状态同步**；
- 修改或重跑前置**查询**时，知悉后续步骤将删除。

左栏标题：**查询范围**。顶栏「查询」控制左栏显隐。

---

## 3. 核心概念定义

| 概念 | 定义 |
| --- | --- |
| **查询 Session** | 画布代表的一次持续性侦查查询 |
| **查询步骤** | 一次查询操作（模板 / 拓展 / 路径分析等），产出该步子图 |
| **步骤过滤** | 查询后、仅作用于**本步结果**的过滤；记入步骤模板；**改本步数据口径** |
| **显示筛选** | 作用于**当前查看范围**（勾选步骤并集之后）；**不改查询口径**；画布与列表同步 |
| **类型筛选** | 显示筛选之一：按实体/关系**类型**显隐，带图例色；顶栏与底栏图例共用状态 |
| **高级筛选** | 显示筛选之一：按属性字段、运算符、值；后续支持多重与/或；新建 Session **默认为空** |
| **查找定位** | 在**显示筛选之后**的可见集合内匹配并高亮、跳转；**不减少**行/点数量（类似 Ctrl+F） |
| **列表列排序** | 仅改变列表展示顺序；不改可见集合 |
| **步骤模板** | 查询参数 + 步骤过滤 + **锚点策略**（见 §6.2） |
| **查询范围（口径）** | 由「纳入显示的步骤」并集 + 各步步骤过滤决定 |
| **当前可见结果** | 查询范围并集 → 高级筛选 → 类型显隐 →（查找仅高亮，图例选中操作见底栏） |

**数据流**

```text
步骤1 查询 → R1 → 步骤过滤 → R1'
步骤2 查询 → R2 → 步骤过滤 → R2'
显示控制：勾选参与显示的步骤集合 S ⊆ {1,2,…}
查询范围 = merge( Ri' for i in S )                    ← 左栏管到这里（口径）

当前可见 = 高级筛选( 查询范围 )
         → 类型显隐( 实体类型 / 关系类型 )
         → 画布 / 列表 / 导出「当前可见」

查找命中 = 在「当前可见」内定位（节点优先，边次之）
列表顺序 = 表头列排序（仅列表）
```

**与周边模块**

| 模块 | 职责 |
| --- | --- |
| 工作台左 rail | 历史查询、模板查询、发起 Session |
| 画布左栏 | 查询范围摘要 + 时间轴（含步骤勾选、步骤过滤） |
| 顶栏 | 显示筛选（实体/关系/高级）、查找、模式切换、界面显隐、编辑/导出等 |
| 底栏图例 | 未选中：类型 chip（与顶栏类型筛选同步）；选中：节点快捷操作 |
| 右栏 | 样式、布局（画布模式） |

## 4. 左栏信息架构（两块）

### 4.1 区块一：范围摘要（顶部）

| 展示项 | 说明 |
| --- | --- |
| Session 名称 | 可选，可后置 |
| **当前查看** | 节点数 · 关系数；口径 = **勾选步骤并集** + **显示筛选（高级 + 类型）**；与画布/列表一致 |
| 查看范围说明 | 如「步骤 2」或「步骤 1–3 并集」 |
| 显示筛选提示（可选） | 如「已筛选 3 条高级条件」；点击聚焦顶栏筛选区，**不在左栏编辑** |

**关于原「范围上限」：不采用。** 步骤卡片可展示本步规模（小字）；摘要顶栏只展示**当前查看**。

### 4.2 区块二：查询时间轴

单步卡片：

```text
☑ 步骤 N  [初始|拓展|路径]                 [⋯]
  查询：模板名 · 参数摘要
  步骤过滤（k）：…                      [编辑]
  [重新执行]  [保存为步骤模板]
```

| 元素 | 规则 |
| --- | --- |
| **显示勾选** | 控制本步是否纳入并集 |
| 步骤过滤 | 绑本步；在步骤子行编辑 |
| 步骤操作 | 重跑、存模板；`⋯` 编辑查询/过滤、删除等 |

**显示控制（并集，已确认）**

| 规则 | 结论 |
| --- | --- |
| 数据合并 | 多步结果为 **并集** |
| 默认 | 新建步骤后默认**勾选该步** |

**变更与清除后续（已确认）**

| 操作 | 对后续步骤 | 说明 |
| --- | --- | --- |
| 修改步骤 N 的**查询参数** | **删除 N 之后所有步骤**（确认提示） | 依赖可能断开 |
| **重新执行**步骤 N | **同左** | 与改查询同类 |
| 仅修改步骤 N 的**步骤过滤** | **不删除**后续步骤 | |
| 修改**显示筛选**（类型/高级） | **不删除**后续步骤 | |
| **删除**步骤 N | **删除 N 及之后** | |

### 4.3 左栏线框示意（已无底部全局过滤）

```text
┌ 查询范围 ───────────────────────────┐
│ 当前查看  156 节点 · 98 关系         │
│ 显示：步骤 1–2 并集                   │
│ 筛选：高级 2 条 →（跳转顶栏）        │
├─────────────────────────────────────┤
│ ☑ 步骤 1  初始  …                   │
│ ☑ 步骤 2  拓展  …                   │
│ ＋ 添加查询步骤                      │
└─────────────────────────────────────┘
```

### 4.4 与现有原型

`graph-canvas-query-panel` 改为**摘要 + 时间轴**；原左栏底部「全局过滤」迁至顶栏「显示筛选」；列表顶栏旧搜索/类型/排序下拉移除。

## 5. 顶栏：显示筛选、查找与布局

### 5.1 顶栏分组（画布/列表共用、位置固定）

建议顺序（**不要求「视图/模式切换」视觉居中**，见 §5.5）：

```text
[ 编辑 ] [ 视图：画布|列表 ] [ 实体▾ ] [ 关系▾ ] [ 高级：摘要▾ ] [ 查找 ] [ 显示：查询|图例|样式… ] [ 快照与下载 ]
```

| 分组 | 能力 | 画布 | 列表 |
| --- | --- | --- | --- |
| 实体 | 类型筛选，**点击展开**面板；色块 + 类型名 + 数量 | ✓ | ✓ |
| 关系 | 同上 | ✓ | ✓ |
| 高级 | 属性条件；摘要常显，点击展开编辑；可选后续与/或 | ✓ | ✓ |
| 查找 | Ctrl+F 式定位；命中 n/m；上一条/下一条 | ✓ | ✓ |
| 显示 | 左栏/底栏图例/右栏显隐 | ✓ | 部分 |

### 5.2 类型筛选（实体 / 关系）

| 规则 | 结论 |
| --- | --- |
| 交互 | **点击展开**面板（非悬停） |
| 选项列表 | **当前查看范围内实际出现的类型**（随步骤勾选、步骤过滤、高级条件变化） |
| 默认状态 | 新建 Session：**各类型均为显示**；类型列表随当前查看动态生成 |
| 颜色 | 与样式/图例一致（`nodeColorMap` / `edgeColorMap`） |
| 与高级关系 | 某类型取消显示后，**高级规则可保留**；该类型无数据、规则不生效 |
| 与底栏图例 | **同一状态**；顶栏勾选 ↔ 底栏 chip 同步（双入口） |

### 5.3 高级筛选

| 规则 | 结论 |
| --- | --- |
| 作用对象 | **当前查看**（勾选步骤并集之后） |
| 新建 Session | **无默认规则** |
| 展示 | 顶栏摘要框（如「3 条条件」）；点击展开完整列表与编辑 |
| 与步骤过滤 | 步骤过滤在左栏步骤上；高级筛选**不替代**步骤过滤 |

### 5.4 查找定位

| 规则 | 结论 |
| --- | --- |
| 心智 | 类似 **Ctrl+F**：定位、高亮、跳转，**不筛掉**数据 |
| 命中范围 | **显示筛选之后**的可见集合（类型 + 高级之后） |
| 画布轮转 | **节点优先，边次之** |
| 列表 | 高亮行并滚入视；与画布命中序号独立或统一队列（实现可选，验收需一致） |
| 快捷键 | 支持 Ctrl/Cmd+F 聚焦查找框；Esc 关闭并清除高亮 |

### 5.5 顶栏布局约定（更新）

| 原约定 | 现结论 |
| --- | --- |
| 顶栏三列网格、模式切换视觉**居中** | **解除**：不再要求画布/列表切换居中；顶栏按分组从左到右自然排布即可 |
| 原因 | 顶栏增加实体/关系/高级/查找后，居中占位挤压筛选区；左右分区（编辑左、筛选中、显示/导出右）更符合 Excel 式习惯 |

实现参考：原 `grid-template-columns: 1fr auto 1fr` 可改为 flex 或左/中/右内容驱动宽度；模式切换可并入「视图」分组，贴左或贴右均可。

### 5.6 列表模式

| 项 | 规则 |
| --- | --- |
| 类型筛选 | 仅顶栏（+ 底栏图例同步），**取消**列表上方实体/关系类型下拉 |
| 搜索 | 仅顶栏查找，**取消**列表「查询」式缩行搜索 |
| 排序 | **表头列排序**（节点表、关系表各自一列活跃排序）；取消顶栏/列表统一排序下拉 |
| 数据口径 | 表格行 = 与画布相同的「当前可见」集合 |

## 6. 查询步骤与步骤模板

### 6.1 步骤规则

新步骤 = 新模板实例 / 拓展 / 路径分析等。拓展须记录锚点（业务 ID）。

### 6.2 锚点策略（fromSelection）

保存为步骤模板时默认 **用时再选**：执行前用户在画布选中实体或边作为锚点。固定实体 ID 仅作案例复现。

### 6.3 步骤模板保存内容

模板引用、默认参数、步骤过滤、锚点策略；不保存节点列表、不保存固定步骤链。

## 7. 底栏图例

| 状态 | 内容 |
| --- | --- |
| 未选中对象 | 实体/关系类型 chip（色块、数量、显隐）；与顶栏**实体/关系**筛选 **双向同步** |
| 选中节点 | 节点快捷操作（详情、拓展、隐藏、设为中心等）；**不**承担类型筛选主编辑 |

顶栏「图例」按钮：控制底栏显隐；类型筛选主入口在顶栏「实体/关系」。

## 10. 验收口径（梳理阶段）

1. 左栏为「查询范围」：**摘要 + 时间轴**；无底部全局/显示过滤配置区。  
2. 时间轴可勾选步骤；**当前查看**数字 = 并集 + 顶栏显示筛选；与画布/列表一致。  
3. 顶栏固定：**实体 / 关系**（点击展开、带色）、**高级筛选**、**查找**；画布与列表切换时控件位置不乱跑。  
4. 底栏类型 chip 与顶栏类型筛选状态一致；选中节点时底栏为操作条。  
5. 查找不减少可见条数；命中在显示筛选之后；画布 **节点先于边** 轮转。  
6. 列表无独立类型下拉与旧搜索条；排序在表头。  
7. 改查询/重跑步骤 N → 删后续；仅改步骤过滤或显示筛选 → 不删后续。  
8. 顶栏 **不要求** 画布/列表切换按钮视觉居中。
