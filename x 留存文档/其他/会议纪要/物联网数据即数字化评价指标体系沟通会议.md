# 物联网数据即数字化评价指标体系沟通会议  
  
  
## 研究事宜  
1、全面梳理各类物联网数据  
```
（1）各类物联网数据能否与工序报验环节强关联
（2）底层逻辑和目前的障碍是什么
（3）什么时候能做到强关联

```
2、全面梳理各类物联网数据与质保资料数据的应关联尽关联情况  
```
（1）目前哪些做到了关联，哪些没有 （2）没做到的为什么不能关联，什么时候能够进行关联

```
3、根据瑞苍调研情况和对数字化评价指标体系的优化情况  
```
（1）能否提交2月试评价结果 （2）3月份能否开展正式评价 （3）如何解决数据的按需适时抓取、统计和评价分析

```
  
1、云检数据对接，是否可以先对接空表、浇筑令数据是否可以先完成对接逻辑  
2、后续浇筑令、任务单信息可能会直接通过闽通获取，相关数据关联逻辑需要统一调整  
3、KPI数据之后可能统一从数据中台获取  
4、路面数据需要推送相应的WBS信息
