# 秦山核电站资产管理平台方案交流  
  
会议时间：2025年8月20日 下午  
会议人员：吴处、王科长、朱、铭觉团队（厉总、胡总、强总、周宇）  
  
1、由厉总为客户进行公司背景介绍  
2、由强总为客户进行资产管理平台方案进行介绍，并在介绍过程中，根据客户的提问展开相应探讨：  
```
（1）RFID识别较感兴趣：
  - 该场景和资产管理中硬件设备关联场景有一定贴合。如RFID+电子围栏的进出管控。
  - 客户对建设成本进行了解
（2）AI对投资项目发起的支撑：
  - 背景：投资项目的审批管理，业务部门从开始申请到后续的流程，走到哪一个流程，对材料输入审批流程，比较模糊
  - 需求：根据提供的项目背景，自动生成审批流程及相关引导
（3）资产管理过程中GIS如何获取
（4）如何通过ai获取政策文件与训练
（5）目前资产管理是在ERP里的
（6）资产管理过程中的数据分析、预警等
（7）资产价值评估如何做，如何实时了解当前行业的现状
（8）数据汇聚的需求

```
3、平台介绍  
```
（1）固定资产，大部分资产安装在现场无法移动，主要是管生产之外可移动的资产
（2）目前有系统：从台账到价值管理都是有的
（3）目前秦山做业务牵头，数创中心做技术牵头，共建资产盘点系统。目前系统基本功能都已经实现。

```
4、需求点：  
```
（1）AI应用：基于资产分类标准目录，进行固定资产的资产卡片自动识别预生成（后续可尝试做试点）
（2）目前对应数据侧只有基础的数据采集、治理、汇聚工作，数据应用尚有欠缺
（3）解放人力

```
