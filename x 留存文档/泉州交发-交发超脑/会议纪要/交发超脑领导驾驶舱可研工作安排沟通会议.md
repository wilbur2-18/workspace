## 交发超脑领导驾驶舱可研工作安排沟通会议  
  
会议时间：2025年12月10日下午2点  
会议地点：线上会议  
参会人：王建春、胡国江、杜俊强、周宇、张博  
  
### 会议主题  
本次会议明确了“交发超脑领导驾驶舱”项目可研阶段的需求与流程，重点讨论了方案设计、资源、数据、安全及数据治理等方面的要点。  
  
### 会议总结  
本次会议主要由王总进行介绍，明确图岳团队需要提供的材料内容、项目范围及相关时间节点。  
（1）领导驾驶舱功能设计  
```
- 第一期需包含主屏及11个业务部门的二级看板，各看板指标需支持逐级下钻，最多可下钻至3级）

```
（2）云资源清单  
```
- 需提供云资源清单，包括虚拟机数量、配置（CPU核数、内存大小、硬盘容量等），以便测算费用。
- 云资源必须按照信创环境实施，包括信创硬件和软件环境的适配，并支持国产密码资源池。

```
（3）数据量需求表  
```
- 需测算治理后的数据量，包括结构化数据和非结构化数据，并提供数据量测算的推导过程。（如数据量测算基于每日数据产生量，并按年推算，每条结构化数据按3-5K的标准计算。）

```
（4）数据安全：  
```
- 需考虑数据安全和应用安全，包括数据库审计、日志审计、堡垒机、漏洞扫描、网页防篡改等安全服务需求。
- 安全需求需列出具体服务内容和数量等级，以便采购部门提供报价。

```
（5）数据治理服务方案  
```
- 需提供数据治理服务方案，包括服务目标、范围、内容、方式、年限和考核指标。
- 数据治理服务以人工服务为主，需根据治理量和颗粒度评估费用，并提供充分的测算依据。
- 考核指标包括数据治理量、治理质量、客户满意度等，总分100分，按得分比例结算费用。

```
  
### 会议结论  
1、会后将建立专项沟通群，由王总提供示例材料进行参考。  
2、图岳团队需尽快完成项目可研相关材料的初稿，并提交给王总进行沟通调整。  
3、根据目前的材料要求，图岳团队将进行内部沟通，尽快明确工作计划，并逐步落实各项材料的梳理。
