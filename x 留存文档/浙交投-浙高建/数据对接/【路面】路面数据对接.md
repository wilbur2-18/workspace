## 【沥青拌合】  
沥青拌合数据主要依托以下数据实现从WBS到沥青生产数据的关联：  
```
WBS数据
沥青运输记录  v_transport_mixture_info  沥青混合料运输表(包括拌合站、运输相关数据和摊铺相关数据)
沥青生产记录  v_yd_asphalt_pb_data_XXX  沥青混合料数据表

```
关联方式如下：  
第一步：实现 WBS- 沥青运输记录 关联，通过项目、标段、桩号、部位名称的关系实现关联  
```
wbs.项目 = 运输记录.摊铺机所属项目（通过 pvi_equ_num摊铺机编号 从 数据接入设备管理表 获取）
wbs.标段 = 运输记录.摊铺机所属标段（通过 pvi_equ_num摊铺机编号 从 数据接入设备管理表 获取）
wbs.桩号 in 运输记录.摊铺过程桩号（包含多个桩号）
wbs.部位名称 包含 运输记录.摊铺层级对应的中文名（通过 项目id、标段id、摊铺层级 从 v_tp_hierarchy摊铺层级表 获取）

```
第二步：实现 沥青运输记录-沥青生产记录 关联，通过拌合站、时间的关系实现关联  
```
运输记录.拌合站id = 生产记录.拌合站id
运输记录.开始接料时间 匹配差值最小的 生产记录.生产时间

```
目前路面系统的都是沥青混凝土（沥青+骨料）的数据，没有沥青碎石（沥青+碎石）的数据
