# 产品介绍 PPT 大纲

> 场景：合作方产品交流  
> 重点：产品思路、整体架构、各产品架构与功能亮点  
> 叙事参考：在既有“智慧风控新范式”PPT 的治理、贯通、引导、协同逻辑上调整，弱化痛点背景和试点路径，减少案例展开，强化产品功能介绍。  
> 不纳入本版主线：算力与模型、技术支持服务及配套费用。  
> 建议页数：16-18 页

## 1. 封面

**标题**：人工智能 + 审计综合解决方案产品介绍  
**副标题**：数据治理、审计图谱与综合分析平台能力交流

**页面重点**

- 面向合作方产品交流，不做客户定制化封面。
- 标题突出“产品介绍”和“功能能力”，不要写成纯解决方案汇报。

## 2. 本次交流内容

**核心内容**

- 介绍整体产品思路：从数据治理到图谱贯通，再到综合分析作业闭环。
- 说明整体产品架构：各平台分别承担什么职责，如何协同。
- 展开各产品功能：结构化数据管理与开发、审计数据图谱平台、审计综合分析平台。
- 对齐合作方后续可重点交流的功能边界、接口边界和演示场景。

**讲述重点**

- 本次不重点讲行业痛点、市场趋势和试点计划。
- 本次重点看“有什么产品、各自做什么、功能如何组织、能力如何贯通”。

## 3. 产品总思路：从数据可用到审计可执行

**建议页面表达**

沿用“风控 PPT”中的四段逻辑，但把表达从案例转为产品能力：

| 产品思路 | 解决目标 | 对应产品能力 |
| --- | --- | --- |
| 治理 | 让数据可读取、可抽取、可计算 | 结构化数据管理、数据治理、文档结构化抽取 |
| 贯通 | 让对象关系可查询、可穿透、可追溯 | 审计数据图谱平台、数据漫游、关系挖掘、图谱分析 |
| 引导 | 让审计方法可配置、可执行、可复用 | 审计技能 Skill、模板、推理任务、批量任务 |
| 协同 | 让审计人员在统一入口完成分析与复核 | 审计综合分析平台、审计助手、任务/结果/证据链 |

**核心文案**

产品体系不是单点 AI 问答工具，而是围绕审计数据治理、关系穿透和作业执行构建的一套产品闭环：底层沉淀数据资产，中层构建关系网络，上层通过综合分析平台完成审计任务执行、结果复核和能力沉淀。

## 4. 整体架构：三类产品协同

**建议画成架构图**

从下到上三层：

1. **结构化数据管理与开发**  
   数据资源目录、数据归集、数据开发、数据治理、数据安全。
2. **审计数据图谱平台**  
   数据漫游、文本结构化抽取、图谱管理、本体建模、数据接入、图谱分析、模板、推理、批量任务。
3. **审计综合分析平台**  
   文档智能处理、多源融合分析、审计助手、审计技能、任务管理、结果管理、证据链。

**协同关系**

- 结构化数据管理与开发提供可信数据资源。
- 审计数据图谱平台把数据资源转成实体、关系、路径和线索。
- 审计综合分析平台把文档、库表、图谱、知识库和技能组织到审计工作台中。

## 5. 端到端产品流程

**建议画成流程图**

数据接入 → 数据资源目录 → 数据探查与治理 → 文本结构化抽取 → 实体/关系入图 → 图谱查询与推理 → 综合分析工作台引用 → 审计任务执行 → 结果复核 → 证据链与技能沉淀。

**功能节点**

- 数据资源统一接入与管理。
- 关键实体自动发现。
- 非结构化文本结构化。
- 图谱本体建模和数据映射。
- 图谱探查、路径分析、关系推理。
- 审计助手统一调度资料、库表、图谱、知识库和技能。
- 分析结果可编辑、下载、溯源、沉淀。

## 6. 产品一：结构化数据管理与开发

**产品定位**

面向审计数据资源的基础管理和治理平台，解决数据资源分散、口径不清、质量不明、接口不可控、安全边界不清等问题，为后续图谱构建和综合分析提供可靠数据底座。

**核心功能**

- 数据资源目录管理：梳理数据库、表、字段、接口、文件等数据资源。
- 数据交换接口管理：统一维护数据库、API、文件等多种交换协议和接口。
- 数据归集：支持多源异构数据抽取、转换、加载，覆盖全量和增量。
- 数据开发：支持数据同步、批量加工、离线任务和运维管理。
- 数据治理：支持数据探查、数据地图、数据标准、数据模型、质量评估、数据清洗、数据比对。
- 数据安全：支持分类分级、加解密、脱敏、权限控制。

**功能亮点**

- 先把数据资源管清楚，再支撑上层智能分析。
- 支持标准和模型驱动的数据治理。
- 为图谱平台提供可映射、可入图、可追溯的数据来源。

## 7. 产品二：审计数据图谱平台架构

**产品定位**

面向审计关系穿透和线索发现的图谱平台，把人员、企业、单位、项目、资金、票据、合同等对象组织为可查询、可推理、可溯源的关系网络。

**建议画成模块架构**

| 模块 | 职责 |
| --- | --- |
| 数据漫游 | 探查库表和字段，发现关键实体和潜在关系 |
| 文本结构化抽取 | 将工商变更、股权变更、高管变更等历史文本转为结构化数据 |
| 图谱管理 | 管理图谱生命周期和图谱权限 |
| 本体建模 | 定义实体、关系、属性、索引、拓扑和溯源链接 |
| 数据接入 | 通过实体映射、关系映射和导入任务完成入图 |
| 知识加工与分析 | 提供图谱探查、路径分析、动态拓展、算法分析 |
| 数据模板 / 推理模板 | 沉淀可复用查询方法和关系推理能力 |
| 批量任务 | 支持 Excel 驱动的规模化图查询和推理执行 |
| 系统管理 | 组织、权限、模型、数据库连接和基础配置 |

## 8. 审计数据图谱平台：数据漫游与文本结构化

**功能介绍**

- 数据表及字段探查：基于大模型对库表进行全量探查，形成数据库表资产。
- 重点实体漫游搜集：识别人员证件、统一社会信用代码、手机号、车牌号等关键实体。
- 潜在关系智能挖掘：从数据中发现人员、企业、单位之间的潜在关系，并辅助生成加工 SQL。
- 股权变更历史治理：提取企业历史股东结构化数据。
- 高级管理人员变更治理：提取企业历史高管结构化数据。
- 企业法人代表变更治理：提取企业历史法人代表结构化数据。

**功能亮点**

- 将“沉睡在库表中的实体信息”变成可分析对象。
- 将“非结构化历史变更文本”变成时间线和结构化清单。
- 为后续构建人企关系图谱、股权穿透、交易关系分析提供基础数据。

## 9. 审计数据图谱平台：图谱管理与本体建模

**功能介绍**

- 图谱生命周期管理：新建、导入、导出、编辑、清除数据、删除。
- 图谱级权限管控：按用户、部门配置访问与编辑权限。
- 工作台驾驶舱：统计图谱总数、节点总量、关系总量、接入数据源数量。
- 实体类型定义：支持表单模式与 SQL 模式定义实体类型。
- 关系类型定义：支持关系名称、属性字段、方向约束、默认显示属性。
- 本体拓扑可视化校验：用拓扑图校验业务模型设计。
- 数据溯源链接：为实体和关系配置 URL 模板，支持从图谱跳转到源数据。

**功能亮点**

- 面向业务人员提供可视化建模能力。
- 面向技术人员保留 SQL 模式和精确配置能力。
- 在入图前完成实体、关系和溯源口径对齐。

## 10. 审计数据图谱平台：数据接入与入图任务

**功能介绍**

- 多源数据接入：注册外部关系型数据库和业务表。
- 实体映射引擎：将数据源字段映射为图谱实体节点。
- 关系映射引擎：将数据源表转换为关系边。
- 关系类型列拆分：单表包含多种关系类型时，可按分类字段拆分入图。
- RANK 字段机制：处理同一对实体间多条同类关系，例如多笔转账记录。
- 数据导入任务调度：通过任务管理数据导入过程，支持执行、中断、追溯、清除和重跑。

**功能亮点**

- 入图过程不是一次性导入，而是可配置、可追溯、可重跑的任务体系。
- 支持复杂关系数据结构，避免关系丢失或冗余。

## 11. 审计数据图谱平台：图谱分析与模板能力

**功能介绍**

- 多模式图谱探查：实体信息查询、路径分析、图查询语句。
- 渐进式探查：通过步数、关系类型、节点类型、方向和过滤条件逐步展开网络。
- 节点/边详情与溯源：查看属性、关系和源数据链接。
- 图谱动态拓展：支持直接拓展和条件拓展。
- 图上分析算法：邻居高亮、最短路径、环检测。
- 多布局可视化：中心布局、社区布局、自动布局。
- 图谱交互工具：撤销/重做、缩放、全屏、下载、历史图谱、显示过滤、图内搜索、AI 自然语言查询。
- 数据模板：将业务查询逻辑沉淀为可复用查询方法。
- 推理模板：通过自然语言描述关系语义，由 AI 挖掘未显式存在的隐含关联关系。
- 批量任务：基于 Excel 批量执行图谱查询和关系推理。

**功能亮点**

- 支持从“查已知关系”升级到“发现未知关系”。
- 查询模板和推理模板让专家经验可以沉淀为可复用能力。
- 批量任务支撑规模化审计分析。

## 12. 产品三：审计综合分析平台架构

**产品定位**

面向审计人员的统一工作入口，将文档、数据库、图谱、知识库、审计技能、任务和结果组织到一个工作台内，承接审计分析、任务执行、结果复核和证据链沉淀。

**建议画成模块架构**

| 模块 | 职责 |
| --- | --- |
| 文档智能处理 | 多格式解析、文档转换、OCR、结构化信息提取 |
| 多源融合分析 | 文档、库表、图谱、知识库统一引用和联动分析 |
| 审计助手 | 自然语言交互、资源引用、技能调用、任务确认 |
| 审计技能 Skill | 沉淀核查路径、判断规则、分析步骤 |
| 任务管理 | 单次任务、跑批任务、子任务、生成技能任务、打包下载任务 |
| 结果管理 | 结果树、结果预览、编辑、下载、打包、历史版本 |
| 证据链 | 结论引用原文资料、源数据和法规依据 |
| 系统管理 | 权限、部署、资源配置、安全控制 |

## 13. 审计综合分析平台：文档处理与多源融合

**功能介绍**

- 多格式解析：支持 PDF、Word、Excel 等主流格式上传与结构化解析。
- 文档转换：支持非标准文档格式转换。
- OCR 引擎：支持文档解析、信息抽取、表格提取、印章识别。
- 统一工作入口：单界面集成文档线索、数据库记录、图谱关联关系。
- 穿透式查询：文档、数据、图谱自动联动，一键追溯实体全貌与资金/股权链路。
- 法规引用与问题定性：接入审计案例知识库、法律法规知识库，为疑点匹配依据。
- AI 辅助分析：自然语言疑点发现、规则匹配、报告生成。

**功能亮点**

- 用户不需要在文档系统、数据库系统、图谱系统之间反复切换。
- 分析过程能保留资料来源、数据来源和法规依据。

## 14. 审计综合分析平台：工作台、任务与结果闭环

**功能介绍**

- 工作台管理：按审计事项组织项目空间。
- 资源管理：统一管理文件资料、数据库表、数据图谱、知识库和已有结果。
- 审计助手：通过自然语言发起分析，支持引用资料、结果、库表和图谱。
- 任务管理：支持单次任务、跑批任务、子任务、生成技能任务、打包下载任务。
- 结果管理：结果树、结果文件夹、预览、编辑、下载、历史版本。
- 证据链管理：结果中的引用编号可定位原文资料片段、来源数据或法规依据。

**功能亮点**

- 从“提出问题”到“执行任务”再到“结果复核”在同一个工作空间完成。
- 分析结果不是一次性回复，而是可管理、可下载、可追溯、可沉淀的审计产物。

## 15. 审计综合分析平台：审计技能 Skill

**功能介绍**

- 技能沉淀：支持手动编写或 AI 自动提炼核查路径、判断规则、分析步骤。
- 技能复用：Skill 可跨项目、跨人员、跨层级导入复用。
- 技能调用：在对话或任务中直接调用审计技能。
- 技能批量执行：Skill 动态组装为 Query 任务，支持百份级资料自动审计与报告产出。
- 技能进化：优秀对话过程、任务配置和分析方法可沉淀为新技能。

**功能亮点**

- 把审计专家经验从个人经验转成可配置、可执行、可复用的产品能力。
- 支持省、市、县等不同层级之间的审计方法复用。

## 16. 产品功能协同示例：股权变更治理到审计分析

**本页不做长案例，只做功能协同示意**

**功能链路**

1. 结构化数据管理与开发：接入工商登记、变更历史、企业基本信息等数据。
2. 审计数据图谱平台：通过文本结构化抽取形成历史股东清单和股权变更时间线。
3. 审计数据图谱平台：将企业、股东、人员、单位关系入图。
4. 审计数据图谱平台：通过路径分析、关系推理发现历史关联和隐含控制关系。
5. 审计综合分析平台：引用图谱结果和原始资料，生成分析结论和证据链。

**页面重点**

- 少讲案例背景，多讲产品功能如何串起来。

## 17. 产品功能协同示例：票据溯源与供应链穿透

**本页不做长案例，只做功能协同示意**

**功能链路**

1. 结构化数据管理与开发：接入发票、合同、供应商、项目资料等数据。
2. 审计数据图谱平台：构建发票、企业、项目、货物、资金关系。
3. 审计数据图谱平台：从单张发票出发递归查询上级发票链路。
4. 审计数据图谱平台：通过最短路径、环检测、条件拓展识别异常链路。
5. 审计综合分析平台：汇总疑点、匹配法规依据、形成可复核结论。

**页面重点**

- 作为功能协同样例即可，不展开成案例故事。

## 18. 合作交流重点

**建议内容**

- 如果合作方关注数据底座：重点讨论结构化数据管理、数据接入、数据治理、数据安全。
- 如果合作方关注图谱能力：重点讨论本体建模、数据映射、图谱查询、推理模板、批量任务。
- 如果合作方关注业务应用：重点讨论综合分析工作台、审计助手、任务结果、证据链、审计技能。
- 如果合作方已有知识库、法规库、案例库：重点讨论如何接入综合分析平台和审计技能体系。

**收束文案**

本次产品体系的核心价值，不在于单个 AI 能力，而在于把数据治理、图谱贯通和审计作业统一组织为可配置、可执行、可复核、可沉淀的产品闭环。
