# 产品介绍 PPT 纯内容稿

## 1. 人工智能 + 审计综合解决方案产品介绍

数据治理、审计图谱与综合分析平台能力交流

关键词：数据治理、关系穿透、审计作业、能力沉淀

## 2. 本次交流内容

1. 整体产品思路：从数据可用到审计可执行。
2. 整体产品架构：三类平台如何协同支撑审计作业。
3. 结构化数据管理与开发：形成可信数据底座。
4. 审计数据图谱平台：形成关系穿透与线索发现能力。
5. 审计综合分析平台：形成统一作业入口与成果闭环。
6. 产品协同链路：说明平台间能力如何贯通。

## 3. 产品总思路：从数据可用到审计可执行

整体产品体系围绕审计数据治理、关系穿透和作业执行构建产品闭环：底层沉淀数据资产，中层构建关系网络，上层完成审计分析、结果复核和能力沉淀。

| 产品思路 | 核心目标 | 对应产品能力 |
| --- | --- | --- |
| 治理 | 让数据可读取、可抽取、可计算 | 数据资源目录、数据归集、数据开发、数据治理、文档结构化 |
| 贯通 | 让对象关系可查询、可穿透、可追溯 | 审计数据图谱、数据漫游、本体建模、关系映射、路径分析 |
| 引导 | 让审计方法可配置、可执行、可复用 | 查询模板、推理模板、审计技能、批量任务 |
| 协同 | 让审计人员在统一入口完成分析与复核 | 综合分析工作台、审计助手、任务管理、结果管理、证据链 |

## 4. 整体架构：三类平台协同形成审计作业闭环

结构化数据管理与开发负责管理数据资源目录，完成数据归集、数据开发、数据治理和数据安全控制，为上层分析提供可信数据资源。

审计数据图谱平台负责将人员、企业、单位、项目、资金、票据、合同等对象组织成可查询、可推理、可溯源的关系网络。

审计综合分析平台面向审计人员提供统一工作台，把文档、库表、图谱、知识库、技能、任务和结果组织到同一个作业空间中。

三类平台形成上下游协同关系：先治理数据，再构建关系，最后进入审计工作台完成作业。

## 5. 端到端产品流程：从数据资源到审计成果

数据接入 → 数据资源目录 → 数据探查与治理 → 文本结构化抽取 → 实体/关系入图 → 图谱查询与推理 → 综合分析工作台引用 → 审计任务执行 → 结果复核 → 证据链与技能沉淀。

关键功能节点：

- 数据资源统一接入和目录化管理。
- 数据表、字段和关键实体自动探查。
- 工商变更、股权变更、高管变更等历史文本结构化。
- 实体类型、关系类型和本体拓扑建模。
- 图谱查询、路径分析、关系推理和批量任务。
- 审计助手引用资料、库表、图谱、知识库和技能。
- 分析结果可编辑、可下载、可溯源、可沉淀。

## 6. 产品一：结构化数据管理与开发

结构化数据管理与开发面向审计数据资源的基础管理和治理，解决数据资源分散、口径不清、质量不明、接口不可控、安全边界不清等问题，为后续图谱构建和综合分析提供可靠数据底座。

| 模块 | 主要职责 |
| --- | --- |
| 数据资源目录管理 | 梳理数据库、表、字段、接口、文件等数据资源，形成统一资源目录 |
| 数据交换接口管理 | 统一维护数据库、API、文件等交换协议和接口配置 |
| 数据归集 | 支持多源异构数据抽取、转换、加载，覆盖全量和增量集成 |
| 数据开发 | 支持数据同步、批量加工、离线任务开发和运维管理 |
| 数据治理 | 支持数据探查、数据地图、数据标准、数据模型、质量评估、清洗和比对 |
| 数据安全 | 支持分类分级、权限控制、加解密和脱敏 |

## 7. 结构化数据管理与开发：让审计数据成为可用资产

数据资源可看清：

- 统一登记数据库、表、字段、接口、文件等数据资源。
- 形成数据地图，支持按来源、主题、权限和质量状态查看数据资产。

数据质量可治理：

- 支持自动数据探查、字段识别、质量评估和异常提示。
- 支持数据标准、数据模型、清洗规则和比对规则管理。

数据加工可执行：

- 支持全量、增量数据归集。
- 支持批量加工、同步任务、离线开发和运维监控。

数据使用可控：

- 支持数据分类分级、脱敏、加解密和权限控制。
- 为图谱入图和综合分析调用提供可追溯的数据来源。

## 8. 产品二：审计数据图谱平台

审计数据图谱平台面向关系穿透和线索发现，将人员、企业、单位、项目、资金、票据、合同等对象组织为可查询、可推理、可溯源的关系网络。

| 模块 | 主要职责 |
| --- | --- |
| 数据漫游 | 探查库表和字段，发现关键实体和潜在关系 |
| 文本结构化抽取 | 将工商变更、股权变更、高管变更等历史文本转为结构化数据 |
| 图谱管理 | 管理图谱生命周期、图谱权限和运行态势 |
| 本体建模 | 定义实体、关系、属性、索引、拓扑和溯源链接 |
| 数据接入 | 通过实体映射、关系映射和导入任务完成入图 |
| 知识加工与分析 | 提供图谱探查、路径分析、动态拓展和算法分析 |
| 模板与批量任务 | 沉淀查询模板、推理模板，支持规模化执行 |
| 系统管理 | 管理组织、权限、数据源和基础配置 |

## 9. 审计数据图谱平台：数据漫游与文本结构化

数据漫游：

- 数据表及字段探查：对库表和字段进行全量探查，形成数据库表资产。
- 重点实体漫游搜集：识别人员证件、统一社会信用代码、手机号、车牌号等审计关键实体。
- 潜在关系智能挖掘：从分散数据中发现人员、企业、单位之间的潜在关系，并辅助生成加工 SQL。

文本结构化抽取：

- 股权变更历史治理：提取企业历史股东结构化数据。
- 高级管理人员变更治理：提取企业历史高管结构化数据。
- 法人代表变更治理：提取企业历史法人代表结构化数据。
- 将历史变更文本整理为时间线、结构化清单和可入图关系。

功能输出：

- 实体清单。
- 变更时间线。
- 历史股东清单。
- 高管变更清单。
- 法人代表变更清单。
- 可入图的实体和关系数据。

## 10. 审计数据图谱平台：图谱管理、本体建模与数据接入

图谱管理：

- 支持图谱新建、导入、导出、编辑、清除数据和删除。
- 支持图谱级权限管控，按用户、部门配置访问和编辑权限。
- 通过工作台驾驶舱统计图谱总数、节点总量、关系总量和接入数据源数量。

本体建模：

- 支持实体类型、关系类型、属性字段、索引和显示属性配置。
- 支持表单模式和 SQL 模式，兼顾业务配置与技术精确控制。
- 支持本体拓扑可视化校验，提前校验业务模型设计。
- 支持实体和关系配置数据溯源链接。

数据接入：

- 支持外部关系型数据库和业务表接入。
- 支持实体映射、关系映射和关系类型列拆分。
- 支持同一对实体间多条同类关系的精细表达。
- 支持数据导入任务执行、中断、追溯、清除和重跑。

## 11. 审计数据图谱平台：图谱分析、模板与批量推理

图谱分析：

- 支持实体查询、路径分析和图查询语句。
- 支持按步数、关系类型、节点类型、方向和过滤条件进行渐进式探查。
- 支持节点详情、边详情、属性查看和源数据溯源。
- 支持直接拓展、条件拓展、邻居高亮、最短路径和环检测。
- 支持中心布局、社区布局、自动布局，以及撤销/重做、缩放、全屏、下载、图内搜索等交互。

模板能力：

- 数据模板：将高频业务查询逻辑沉淀为可复用查询方法。
- 推理模板：通过自然语言描述关系语义，辅助挖掘未显式存在的隐含关联关系。
- 模板生命周期：支持创建、配置、执行、复用和管理。

批量任务：

- 支持基于 Excel 批量执行图谱查询。
- 支持批量执行关系推理任务。
- 支持任务历史、结果查看和结果复用。

## 12. 产品三：审计综合分析平台

审计综合分析平台面向审计人员，将文档、数据库、图谱、知识库、审计技能、任务和结果组织到一个工作台内，承接审计分析、任务执行、结果复核和证据链沉淀。

| 模块 | 主要职责 |
| --- | --- |
| 文档智能处理 | 多格式解析、文档转换、OCR、结构化信息提取 |
| 多源融合分析 | 文档、库表、图谱、知识库统一引用和联动分析 |
| 审计助手 | 自然语言交互、资源引用、技能调用、任务确认 |
| 审计技能 Skill | 沉淀核查路径、判断规则和分析步骤 |
| 任务管理 | 管理单次任务、跑批任务、子任务、生成技能任务、打包下载任务 |
| 结果管理 | 管理结果树、结果预览、编辑、下载、打包和历史版本 |
| 证据链 | 将结论关联到原文资料、源数据和法规依据 |
| 系统管理 | 管理权限、部署配置、资源配置和安全控制 |

## 13. 审计综合分析平台：文档处理与多源融合分析

文档智能处理：

- 支持 PDF、Word、Excel 等主流格式上传与结构化解析。
- 支持非标准文档格式转换。
- 支持 OCR 文档解析、信息抽取、表格提取和印章识别。
- 支持资料预览、解析状态查看和结构化结果引用。

多源融合分析：

- 在统一工作入口中集成文档线索、数据库记录、图谱关联关系和知识库依据。
- 支持穿透式查询，围绕对象追溯资料、数据、关系和法规依据。
- 支持接入审计案例知识库、法律法规知识库，为疑点定性提供依据。
- 支持 AI 辅助疑点发现、规则匹配和报告生成。

能力输出：

- 资料结构化结果。
- 多源资源引用。
- 疑点分析结果。
- 法规与案例依据。
- 可追溯的分析过程。

## 14. 审计综合分析平台：工作台、任务与结果闭环

工作台管理：

- 按审计事项组织项目空间。
- 支持我的工作台、共享工作台和工作台权限范围。
- 统一管理文件资料、数据库表、数据图谱、知识库和已有结果。

任务管理：

- 通过审计助手发起分析任务，支持引用资料、结果、库表和图谱。
- 支持单次任务、跑批任务、跑批子任务、生成技能任务和打包下载任务。
- 支持排队、运行、完成、失败、重跑、中止等任务状态管理。

结果管理：

- 支持结果树、结果文件夹、结果预览、编辑、下载和打包。
- 支持历史版本查看和结果复用。
- 支持对话内容保存为结果。

证据链管理：

- 结果中的引用编号可定位原文资料片段、来源数据或法规依据。
- 支持审计人员复核、确认和修改结论。

## 15. 审计综合分析平台：审计技能 Skill 与能力沉淀

技能沉淀：

- 支持手动编写或 AI 自动提炼核查路径、判断规则和分析步骤。
- 可从优秀对话过程、任务配置和分析方法中沉淀新技能。
- 技能可包含资料匹配方式、分析规则、执行步骤和输出格式。

技能复用：

- 支持我的技能、共享技能和工作台技能。
- 支持跨项目、跨人员、跨层级复用。
- 支持技能文件、版本回退和共享管理。

技能执行：

- 可在对话或任务中直接调用审计技能。
- 支持技能动态组装为 Query 任务。
- 支持批量资料自动审计和报告产出。

能力输出：

- 标准化审计方法。
- 可复用审计规则。
- 可执行任务流程。
- 可沉淀分析成果。

## 16. 产品协同示例：股权变更治理到审计分析

功能链路：

1. 结构化数据管理与开发接入工商登记、变更历史、企业基本信息等数据。
2. 数据治理能力对股权变更、高管变更、法人代表变更等历史文本进行结构化抽取。
3. 审计数据图谱平台将企业、股东、人员、单位等对象及变更关系入图。
4. 审计数据图谱平台通过路径分析、关系推理发现历史关联、交叉任职和隐含控制关系。
5. 审计综合分析平台引用图谱结果、原始资料和法规依据，生成可复核分析结论。

能力输出：

- 企业历史股东清单。
- 股权变更时间线。
- 企业、人员、单位关系图谱。
- 关系穿透路径和疑点说明。
- 带来源证据的审计分析结果。

## 17. 产品协同示例：票据溯源与供应链穿透

功能链路：

1. 结构化数据管理与开发接入发票、合同、供应商、项目资料和资金数据。
2. 审计数据图谱平台构建发票、企业、项目、货物、资金等对象关系。
3. 审计数据图谱平台从单张发票出发，递归查询上级发票链路和供应链关系。
4. 审计数据图谱平台通过最短路径、环检测、条件拓展识别异常链路。
5. 审计综合分析平台汇总疑点、匹配法规依据、形成可复核结论和证据链。

能力输出：

- 发票上下游链路。
- 供应商、项目、货物、资金关系网络。
- 异常链路提示。
- 相关合同、票据和资金记录引用。
- 可编辑、可下载、可追溯的审计分析结果。
